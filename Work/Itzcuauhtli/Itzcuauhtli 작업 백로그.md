## 카테고리별 분류 및 작업 ID 체계

작업 ID는 접두사 `IZ-`와 3자리 번호(`1xx`~`8xx`)로 부여합니다.  
**첫 자리는 카테고리 도메인, 뒤 두 자리는 순번**입니다.

| 카테고리 | 도메인 범위 | 예시 |
|---|---|---|
| **1xx** | MCP 도구 & 엔드포인트 | list, read, search 도구 구현, 파라미터 유효성 검사 |
| **2xx** | 보안 & 권한 격리 | 읽기 전용 강제, 경로 탈출 방지, 토큰 인증 |
| **3xx** | 인덱싱 & 캐싱 | 로컬 캐시, 빠른 검색 색인, TF-IDF / 전문 검색 |
| **4xx** | 에이전트 연동 & 클라이언트 | Hermes / Dovie / Claude Desktop 연동 테스트 |
| **6xx** | 관측 & 감사 로그 | MCP 호출 로깅, 레이턴시 모니터링 |
| **7xx** | 배포 & 서비스 운영 | NAS Docker 컨테이너화, systemd 서비스 |
| **8xx** | 문서 & 개발환경 | API 명세, 아키텍처 문서, 테스트베드 환경 |

## 1. 신규 착수 대기 작업

### IZ-201 — 상위 디렉터리 경로 탈출(Path Traversal) 방어 검증
- **상태**: 착수 대기
- **우선순위**: P0 (긴급)
- **목적**: `../` 등을 이용한 볼트 루트 밖 시스템 파일 무단 접근 차단.
- **완료 기준**:
  - [ ] 절대 경로 및 상대 경로 정규화 후 Vault Root 범위 검사
  - [ ] 탈출 시도 시 403 Forbidden 에러 반환 검증

### IZ-701 — NAS Docker 프로덕션 배포 및 읽기 전용 마운트
- **상태**: 착수 대기
- **우선순위**: P1 (높음)
- **목적**: UGREEN NAS 상에서 `:ro` 볼륨 마운트로 안전하게 상시 구동.
- **완료 기준**:
  - [ ] Dockerfile 및 docker-compose 서비스 등록
  - [ ] NAS 로컬 네트워크 포트 바인딩 및 헬스체크 통과
