# [BN-INT-001] 프로젝트 전체 브랜치 dev-codex 통합

## 요약

사용자 요청에 따라 프로젝트 내에서 개별적으로 분기되어 진행되던 모든 활성 브랜치(`origin/dev-nas`, `origin/dev`, `dev-mac`, `dev-docs`, `dev-codex`)를 `dev-codex` 기준으로 단일 통합 커밋(`0cc0be5`)에 병합 완료했다.

통합 과정에서 NAS 신규 NPM(Nginx Proxy Manager) exporter compose 및 Prometheus 설정 추가, `dev` 브랜치의 Kestrel / TelemetryIngest / carrier_pigeon 워크플로우 갱신을 흡수했다. 상충되는 변경에 대해서는 telemetry 최신 project label 회귀 테스트와 Magpie → Owlie 리네임을 보존하고, Swallow의 AI 검증·MLflow·뉴스 영향도·백테스트·가격표시·SQL 도구를 삭제/축소하려던 `dev-mac`의 구버전 변경을 배제하여 최신 `dev-codex`의 기능(22노드, 39 계약 테스트, 매크로 3대 지표 수집 및 쉼표 포맷)을 온전히 유지했다.

통합 후 Swallow 39 pass, Telemetry 131 pass(48 skip, 0 fail), NPM fixture 통과, 실제 NAS Grafana SQL 21 pass 및 graphify update를 검증 완료했다. 신규 n8n 및 모니터링 컴포넌트의 실서버 배포와 전체 E2E 검증은 미실행 상태이며, 기존 Draft PR #5 업데이트를 통해 사용자가 최종 main 머지를 진행할 예정이다.

## 1. 작업 배경 및 문제 분석

### 발생 현상 / 요구사항
* 여러 작업자(에이전트) 및 환경(NAS, Mac, Docs)에서 각자 개발 브랜치가 분기되어 운영되면서 형상 파편화가 발생함:
  - `origin/dev-nas` (`0fce240`): NAS 모니터링 스택(NPM exporter) 구현
  - `origin/dev` (`4a865c5`): Kestrel, Hermes TelemetryIngest, carrier_pigeon 워크플로우 수정
  - `dev-mac` (`54eb212`): 과거 Mac 로컬 작업 내역 (Swallow 구버전 축소 변경 포함)
  - `dev-docs` (`138766a`): 문서 정정 및 트러블슈팅 기록
* 사용자가 프로젝트의 모든 브랜치를 `dev-codex`로 단일 머지하도록 공식 요청함.

* `dev-claude`, `dev-agy`, `main` 및 기타 기존 브랜치는 이미 현재 브랜치의 조상임을 확인.

## 2. 해결 방안 및 충돌 해결 기준

### 채택된 통합 기준
1. **신규 인프라 및 워크플로우 기능 흡수**:
   - `dev-nas`의 NPM exporter Dockerfile, Python 스크립트, compose 파일 및 Prometheus 타깃 설정을 온전히 반영.
   - `dev`의 n8n 워크플로우(Kestrel, TelemetryIngest, carrier_pigeon) 갱신 사항 반영.
   - `origin/dev` export에서 누락되었던 Telemetry Ingest 3종 specs(`hermes_session_samples`, `hermes_tool_events`, `hermes_tool_log_events`)를 최신 canonical `Validate and Split Telemetry` jsCode 재사용으로 정렬 완료 (스키마 2/3에서 3종출력·noop·오류입력 runtime fixture 통과, 배포 미실행).
2. **충돌 해결 원칙 (최신 기능 및 안전성 보존)**:
   - **Telemetry**: 최신 project label(`kimdove` 방어) 회귀 테스트 보존.
   - **네이밍**: `Magpie` → `Owlie` 리네임 보존.
   - **Swallow**: `dev-mac`의 AI 검증, MLflow 8인자 매매, 뉴스 영향도, 백테스트, 가격 표시, SQL 검증도구 삭제/축소 변경을 **채택하지 않고**, 최신 `dev-codex`의 22노드 고도화 파이프라인(매크로 지표 수집, 쉼표 포맷팅, 39 계약 테스트)을 유지.
   - **Docs**: 원거래시각은 실행 요약에만 보존되고 DB에는 별도 컬럼이 없다는 정정 내용 보존.
