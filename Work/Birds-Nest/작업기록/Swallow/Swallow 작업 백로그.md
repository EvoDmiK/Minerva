### SW-002 — 재실행에 따른 중복 모의매매 방지

- [ ] 완료
- **우선순위:** P1
- **담당 제안:** Claude Code / dev-claude
- **근거:** `n8n/Swallow/workflows.json:226; mcp/swallow-mcp/schema.sql:298`
- **확인 내용:** 중복 제거 Set은 실행마다 초기화되고 체결 함수는 기사·주문 중복을 막지 않는다. 같은 기사가 두 실행 모두 통과하는 것을 재현했다.
- **완료 기준:** 영속적인 주문 식별자와 원자적인 중복 방지를 적용한다. 동일 기사 재실행·동시 호출에서도 같은 자동 주문이 중복 체결되지 않아야 한다. 실패 후 재시도 정책을 기록한다.
- **검증·커밋·결과 기록:** 미등록

### SW-003 — 매크로 수집기의 하드코딩 자격증명 제거

- [ ] 완료
- **우선순위:** P1
- **담당 제안:** 담당 미배정
- **근거:** `scripts/sync-macro-indicators.js:34`
- **확인 내용:** DB 비밀번호 문자열이 환경변수의 기본값으로 저장되어 있다. 비밀 값 자체는 문서에 기록하지 않는다.
- **완료 기준:** 기본값을 제거하고 환경변수가 없으면 접속 전에 실패해야 한다. 실제 자격증명이면 교체 여부를 별도로 확인하고 저장소 이력에 남은 노출을 처리한다. 운영 자격증명 변경은 별도 실행 범위를 확인한다.
- **검증·커밋·결과 기록:** 미등록
