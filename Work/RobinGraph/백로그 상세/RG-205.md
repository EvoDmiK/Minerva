# RG-205 — 구조화 질의 계약·정답 평가셋·현재 기준선

[[Work/RobinGraph/RobinGraph 작업 백로그|← 전체 백로그]] · [[Work/RobinGraph/작업기록/2xx 검색·RAG·그래프 질의/작업 백로그|← 2xx 작업 백로그]]

- **상태**: 진행 중 (2026-10-22 계약·기준선·에이전트 평가셋 구축 검증 완료; 사람 미검토 분리, 운영은 향후 별도 승인)
- **우선순위**: P1 (높음)
- **권장 담당**: Claude (데이터/평가셋 구축), Codex (독립 평가·계약 리뷰)
- **목적**:
  - 사용자 자연어 질의 원문에서 추출해야 할 질의 유형 및 조건 파라미터(종 ID 후보, 분류목, 먹이 범주, 서식지, 같음/다름, 부정, 지역 범위, 특정 식물, 자료 부족)를 명확히 정의하는 표준 정형 스키마 계약 수립
  - 정규식 한계를 극복하고 모델/파서 성능을 엄격히 평가할 수 있는 사람 검토 기반 Gold 정답 평가셋 구축 및 현재 시스템 기준선(baseline) 측정
- **범위 및 변경 목표**:
  - 허용 질의 유형(query kind)을 7개로 고정: `common_taxonomy`, `same_genus`, `korea_same_genus`, `order_fruit`, `specific_fruit`, `habitat_shared_diet`, `habitat_different_diet`
  - 정답 평가셋(gold dataset) 구성:
    - 실제 사용자 실패 3문장("새중에서"의 `specific_fruit`/`insufficient_data` 오분류, "나무열매" 및 "어떤게 있어"의 `clarify` 오분류) 명확히 구분하여 포함
    - 일상적 자연어 구어체, 띄어쓰기 변형, 일반적인 오타, 어순 도치, 동일 범주 대조군 및 원문에 명시되지 않은 조건을 추론해 추가하지 않는지 확인하는 대조 질문 포함
    - 그래프 질의와 무관한 질문(negative/out-of-domain) 포함
  - 엄격한 데이터 경계 Gold 표준화:
    - 일반 열매 질의 vs 감나무 등 특정 식물 질의(`insufficient_data`) 구분
    - 나무열매 질의 시 `(나무·풀 구분 없음)` 한계 고지 필드 명시
    - 서식지 범주 일치 vs 실제 공존(동소성) 한계 안내 구분
  - 데이터셋 분리 원칙:
    - RG-203의 664개 기계 생성 단위 회귀 케이스는 독립적인 자연어 품질 증거로 간주하지 않음
    - 사람 검토 Gold 세트와 프롬프트/임계치 튜닝용 데이터셋, 최종 평가용 고정 홀드아웃(holdout) 데이터셋을 엄격히 분리
  - 정량 평가 지표 정의:
    - 질의 유형 분류 정확도(Type Accuracy), 조건 파라미터 추출 정확도(Slot Accuracy), 잘못된 실행률(False Execution Rate), 적정 보류율(Appropriate Abstain/Clarify Rate), p50/p95 지연시간
    - 구체적인 목표 합격선 및 지연/비용 상한 수치는 기준선(baseline) 측정 후 구현 착수 전에 고정 (현재는 '미정'으로 명시)
- **예상 대상 파일 / 모듈**:
  - `src/robingraph/retrieval/graph_questions.py` (현재 파서 기준선 측정 대상)
  - `src/robingraph/retrieval/graph_intent_schema.py` (예정: 정형 DTO 스키마 정의)
  - `data/eval/graph_questions/gold_queries.jsonl` (예정: 사람 검토 정답 세트)
  - `data/eval/graph_questions/tuning_queries.jsonl` (예정: 파라미터 조정용 세트)
  - `data/eval/graph_questions/holdout_queries.jsonl` (예정: 고정 평가용 홀드아웃 세트)
  - `scripts/evaluate_graph_intent_baseline.py` (예정: 현재 기준선 측정 스크립트)

  - [x] 현재 정규식 파서 기반의 기준선(게이트 오실행 0%, 커버리지 55%, 적정보류 100%) 실측 완료
