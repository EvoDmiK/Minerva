### RG-215 — 조건으로 새 찾기(새 탐색기): 다중 조건 구조화 그래프 검색 및 탐색 인터페이스

- **상태**: 완료 (2026-11-11 사용자 승인 후 새소리 제외 운영 배포·실제 검증 완료)
- **우선순위**: P2(보통) — 사용자 구현 승인
- **권장 담당**: Codex(검토·통합·TEST 배포), Claude(backend 구조화 검색·API), Antigravity(UI 탐색 인터페이스), Writer(기록·Obsidian 동기화)
- **등록 경위**: 2026-11-10 사용자 승인으로 협업 착수. 자연어 파서를 거치지 않고 기존 구조화 graph 검색을 재사용하여 다중 조건(분포·분류군·서식지·먹이) 기반으로 조류를 탐색하고 결과를 직관적으로 조회하는 기능 구현 및 TEST 실사 완료.
- **목적**:
  - 자연어 입력 없이도 필터 선택(분포, 목·과·속 분류군, 서식지, 복수 먹이)만으로 조건을 조합하여 원하는 조류를 정밀하게 탐색할 수 있는 전용 엔드포인트(`GET /v1/taxa/explore`)와 탐색 인터페이스를 제공한다.
  - 검색 결과의 생태적 근거, 출처, 데이터 커버리지, 도감 링크를 명확히 제시하여 정보 신뢰도를 확보한다.
- **범위 및 변경 목표**:
  - **분포 범위**: 4종 스코프(`all`, `korea`, `outside`, `unknown`) 완전 지원.
  - **분류군 필터(v1 계약)**: 목(order)·과(family)·속(genus) 학명 1단어(`^[A-Z][a-z]+$`) 또는 검토된 한국어 목·과·속 이름만 지원. 결과는 항상 **종(species) 단위**이며, 종·아종 입력 시 부모 범위로 넓히지 않고 HTTP 422(`taxon_rank_unsupported`)로 거절.
  - **서식지 및 먹이 조건**: 서식지는 AVONET 대표 서식지 11종 중 단일 선택(복수 전송 시 422). 먹이는 EltonTraits 먹이 키 1~10개 선택 시 **모두(AND)** >0%인 종을 필터링하고 선택된 먹이 비율의 **합산 내림차순(DESC)** 정렬 (동점 시 한국어 이름순).
  - **자연어 파서 우회**: LLM / Jev / 벡터 의도 파서를 경유하지 않고 기존 고정 Cypher 구조화 그래프 쿼리(`graph_question_handler`)를 직접 재사용하여 결정론적이고 안전한 응답 보장.
  - **결과 정보 충실도**: 각 결과에 실제 증거 링크, 출처 명시, 자료 커버리지(자료 부재 `insufficient_data`와 빈 결과 `empty` 구분), 첫 페이지 20종 상한 및 `has_more` 공개, 도감(Bird Profile) 연결 지원.
  - **UI 및 반응형**: 데스크톱(1280px) 및 모바일(390px/320px) 뷰포트 지원, 키보드 인터랙션, 공유 가능한 URL 상태 복원(선택 필터 쿼리스트링 유지), 비동기 레이스 컨디션 방어.
- **대상 파일 및 모듈 (15개 파일 통합)**:
  - Backend: `src/robingraph/retrieval/graph_questions.py`, `src/robingraph/api/services.py`, `src/robingraph/api/drf/serializers.py`, `views.py`, `urls.py`, `openapi*.json`
  - Frontend: `src/robingraph/api/static/` (`explore.html`, `explore.css`, `explore.js`, `index.html`, `styles.css`), `tests/frontend/explore_ui.test.js`
