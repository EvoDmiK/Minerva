# RG-203 — 그래프 관계 기반 질의응답 (분류 계통·속 관계·생태 및 먹이 공유 질의)

[[Work/RobinGraph/RobinGraph 작업 백로그|← 전체 백로그]]

- **상태**: 진행 중 (착수 및 현황 점검)
- **우선순위**: 보통 (P2)
- **권장 담당**: Claude (데이터·검색·GraphRAG) / Antigravity (UI) / Codex (통합·검증·TEST환경) / Writer (문서)
- **목적**:
  - 기존의 단일 종 사실 조회, 이름 해소, 유사종 추천을 확장하여, 두 종 간 분류 관계, 동일 속 종, 특정 분류군과 식성/서식지 교집합 등 Neo4j 그래프의 다중 노드 및 엣지(`PARENT_OF`) 경로를 탐색하는 복합 관계 자연어 질의응답 기능 구축
  - 독립 자연어 질문별 종 목록 표출, 분류학적 계층 경로(LCA) 시각화, 학술 출처(EltonTraits, AVONET 등) 표기 및 자료 부족 시 정직한 안내 체계 확립
- **범위 및 변경 목표**:
  - 두 종 분류 관계 / 공통 상위분류 및 계통 경로 탐색 (LCA 및 분기 속/과/목 식별, 진화적 계통 거리가 아닌 분류학적 계층 경로로 기술)
  - 같은 속(Genus)에 속하는 조류 목록 조회
  - 국내 출현 기록(reviewed occurrence) + 같은 속 복합 조건 필터
  - 특정 분류군(참새목 등) + 식성 형질(`Fruit > 0` 또는 `Frugivore` 주식성 분리 정의)
  - 숲 서식지 + 기준 종(직박구리 등)과의 먹이 범주 교집합 조회
  - **추가 수용 질의**: 청둥오리와 서식지가 겹치면서 먹이가 다른 새 (실제 공존이 아닌 데이터상 서식지 범주 일치 한계 안내 포함)
  - **데이터 무결성 원칙**: 일반 과실식(Frugivory)과 특정 식물 열매 공유를 엄격히 구별하고, 후자는 원천 출처 데이터가 없으면 임의 환각 없이 "자료 부족"으로 안내
  - **범위 한계선**: 최초 구현 범위는 **독립 자연어 질문별 단일 턴 처리**에 한정하며, 조건 이어가기(대화 상태 기억 및 문맥 유지)는 이번 구현 범위에서 제외하고 향후 후속 과제로 명시 (대화 상태 기억 구현 완료 주장 배제)
  - UI 렌더링: 종 목록 카드, 분류학적 계층 경로 시각화, 출처 배지, 자료 부족 안내 메시지
- **예상 대상 파일 / 모듈**:
  - `src/robingraph/retrieval/graph_questions.py` (신규: 관계 질의 해석 및 그래프 질의 오케스트레이션)
