# RG-203 — 그래프 관계 기반 질의응답 (분류 계통·속 관계·생태 및 먹이 공유 질의)

[[Work/RobinGraph/RobinGraph 작업 백로그|← 전체 백로그]]

- **상태**: 진행 중 (착수 및 현황 점검)
- **우선순위**: 보통 (P2)
- **권장 담당**: Claude (데이터·검색·GraphRAG) / Antigravity (UI) / Codex (통합·검증·배포) / Writer (문서)
- **목적**:
  - 두 종 간 분류 관계, 동일 속 종, 특정 분류군과 식성/서식지 교집합 등 Neo4j 그래프의 다중 노드 및 엣지 경로를 탐색하는 복합 관계 질의를 자연어로 해결
  - 조건 이어가기(대화 문맥 유지), 종 목록 표출, 계통/연결 경로 시각화, 학술 출처(EltonTraits, AVONET 등) 표기 및 자료 부족 시 정직한 안내 체계 구축
- **범위 및 변경 목표**:
  - 두 종 분류 관계 / 공통 상위분류 및 계통 경로 탐색 (LCA 및 분기 속/과/목 식별)
  - 같은 속(Genus)에 속하는 조류 목록 조회
  - 국내 출현 기록(reviewed occurrence) + 같은 속 복합 조건 필터
  - 특정 분류군(참새목 등) + 식성 형질(과실식 등) 결합 조회
  - 숲 서식지 + 기준 종(직박구리 등)과의 먹이 범주 교집합 조회
  - **데이터 무결성 원칙**: 일반 과실식(Frugivory)과 특정 식물 열매 공유를 엄격히 구별하고, 후자는 원천 출처 데이터가 없으면 임의 환각 없이 "자료 부족"으로 안내
  - UI 렌더링: 종 목록 카드, 계통/연결 경로 시각화, 출처 배지, 자료 부족 안내 메시지
- **예상 대상 파일 / 모듈**:
  - `src/robingraph/graph/` (Neo4j Cypher 쿼리)
  - `src/robingraph/retrieval/` (관계 질의 해석 및 GraphRAG 오케스트레이션)
  - `src/robingraph/api/` (API 엔드포인트 및 페이로드 계약)
  - `src/robingraph/api/static/chat.js` (UI 렌더링)
  - `tests/` (단위 및 회귀 테스트)
- **완료 기준 (Acceptance Criteria)**:
  - [ ] 두 종 간 분류 관계 및 계통 분기점(LCA) 질의 처리 및 경로 출력
  - [ ] 동일 속 및 국내 기록+동일 속 복합 조건 종 목록 조회
  - [ ] 분류군+식성(참새목+열매) 및 서식지+먹이공유(숲+직박구리) 교집합 질의 처리
  - [ ] 특정 식물 종 열매 공유 등 출처 미확보 질의에 대한 자료 부족(정직한 안내) 응답 확인
  - [ ] 종 목록, 연결 경로, 출처 표기 및 자료부족 안내 UI 렌더링 검증
  - [ ] 단위/통합 테스트 전수 통과 및 NAS TEST 환경 실서버 질의 검증 통과
- **선행 조건 / 의존성**:
  - Neo4j 분류 체계 및 EltonTraits/AVONET 생태 형질 그래프
  - Claude, Codex, Antigravity 간 API 계약 확립
  - 사용자 명시 승인 (2026-10-22 착수 승인)
