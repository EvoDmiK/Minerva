# RG-208 — 통합·관측·TEST 비교·단계적 전환

[[Work/RobinGraph/RobinGraph 작업 백로그|← 전체 백로그]] · [[Work/RobinGraph/작업기록/2xx 검색·RAG·그래프 질의/작업 백로그|← 2xx 작업 백로그]]

- **상태**: 완료 (2026-10-22 전체 분류군×형질 일반화 수정 검증 범위 완료; 단, 모든 자연어 지원 완료가 아니며 더 넓은 별도 표현 검증은 후속 과제 명시, 운영은 향후 별도 승인)
- **우선순위**: P1 (높음)
- **권장 담당**: Codex (통합 검증·TEST 배포), Claude (검색 로직), Antigravity (필요 시 UI), Writer (문서 기록)
- **목적**:
  - RG-205, 206, 207에서 구축된 의미 기반 질의 파이프라인을 기존 서비스 계층에 통합하고, 기능 플래그(feature flag)와 섀도우(shadow) 비교를 통해 안전하게 단계적 전환 수행
  - MLflow 관측성을 연동하여 실서비스 환경에서의 라우팅 신뢰도, 지연시간, 자원 사용량을 정량적으로 검증하고 결함 발생 시 즉각적인 롤백 체계 확립
- **범위 및 변경 목표**:
  - 사용자 실제 질의 피드백 및 분류군·형질 일반화 목표 (2026-10-22 수정 완료):
    - **실제 TEST 실패 사례**: "까마귀과면서 열매를 먹는 새는 어떤 종이 있어?" 질의 시 `clarify` 실패 발생
    - **요구 범위 명확화**: "모든 분류군에 해야지 / 먹이에 대해서만 진행할 거야?"
    - **한계 공식 인정**: 이전 완료 설명과 검증이 `목(order)` 및 단순 열매 전용에 국한되어 있었음을 Root가 공식 인정. 기존 7개 고정 유형 및 40건 홀드아웃 통과가 자유 질의 전체 지원을 의미하지 않음을 명확히 함.
    - **수정 목표**: 활성 5대 계급(목 46, 과 252, 속 2,376, 종 11,131, 아종 19,879; 총 33,684 분류군; 강 노드 0건 미지원) × 근거 있는 형질(먹이, 서식지, 생활양식, 수치 형질 등 AVONET/EltonTraits 15개 형질 필드) 조합 질의 지원
    - **역할 분담**: Claude(core 파서/라우터 개선), Root(실제 분류/형질 인벤토리 감사 및 통합 배포, `inventory.json`, `trait-inventory.json`), Writer(독립 44건 의미 검토 보고서 작성 및 문서화, `independent-meaning-review.md`). Antigravity는 CLI panic/편집 정체로 독립 QA 미확보.
  - 기능 플래그(Feature Flag) 및 섀도우(Shadow) 비교:
    - 기본 라우팅은 기존 정규식 경로를 유지하면서, 섀도우 모드로 신규 의미 파이프라인을 병행 호출하여 동일 gold 평가셋에 대한 응답 일치도 및 성능 비교 (동기 실행 방식)
    - 단계적 카나리 전환 체계 (`shadow` -> `active` -> `off` -> `active`) 전수 검증
  - 회귀 검증:
    - 기존 명시적 intent/filter(`profile` 빈 필터 허용 등)
    - 사용자 지정 `species_scope` (`all`, `korea`, `outside`, `unknown` 4개 범위 모두 실제 API 통과)
    - 단일 종 사실 조회 및 이름 해소
    - 백엔드 장애 시 fallback 및 자료 부족(`insufficient_data`) 응답
  - MLflow 관측성 연동:
    - 라우팅 경로, 신뢰도 점수, 보류 사유, p50/p95 응답 지연시간, 사용 모델 버전 메트릭 로깅
    - **보안/개인정보 엄수**: 인증 정보, API 키, 불필요한 사용자 개인정보/원문은 일체 로깅하거나 저장하지 않음 (실험 33 실제 저장 조회 확인)
  - 실제 TEST 환경 배포 및 엔드투엔드 실서버 검증:
    - 16GB Mac mini .97 (`robingraph-api-test`) 배포 완료 (`robingraph-api:test-taxonomic-traits-9adf41538e2e`) 및 `test-health-verify.json` 통과
    - 실제 TEST DB 및 루프백 엔드포인트(`http://127.0.0.1:8000/v1/chat`) 실측 (독립 44건 회귀 전수 통과)
    - 공개 TEST 서버(`https://robingraph-test.dove-nest.com`) Playwright Chromium PC(1280px) 및 모바일(390px) 각 6질문 총 12건 실측 통과
  - 정량 벤치마크 비교:
    - 임베딩 순차 호출 지연 실측: cold 2,268ms, warm 5회 472~549ms. 컨테이너 메모리 159.7MiB 관측 (소표본 순차 측정이며 부하/최대 용량 시험 아님)
  - 롤백 및 안전 보장:
    - 결함 또는 성능 저하 감지 시 플래그 즉각 오프로 기존 정규식 경로 완전 복원 (off 모드 7질문 fingerprint 동일)
    - 공유 TEST Neo4j 벡터 인덱스는 테스트용으로 임의 삭제하거나 교체하지 않음
  - 운영 배포 승인 게이트:
    - TEST 배포 및 실측 검증 완료 후, 사용자 명시 승인 전에는 운영 배포를 일체 수행하지 않음 (운영 배포 0건, DB 쓰기 0건, Git commit/push 0건)
