# RG-208 — 통합·관측·TEST 비교·단계적 전환

[[Work/RobinGraph/RobinGraph 작업 백로그|← 전체 백로그]] · [[Work/RobinGraph/작업기록/2xx 검색·RAG·그래프 질의/작업 백로그|← 2xx 작업 백로그]]

- **상태**: 착수 대기
- **우선순위**: P1 (높음)
- **권장 담당**: Codex (통합 검증·TEST 배포), Claude (검색 로직), Antigravity (필요 시 UI), Writer (문서 기록)
- **목적**:
  - RG-205, 206, 207에서 구축된 의미 기반 질의 파이프라인을 기존 서비스 계층에 통합하고, 기능 플래그(feature flag)와 섀도우(shadow) 비교를 통해 안전하게 단계적 전환 수행
  - MLflow 관측성을 연동하여 실서비스 환경에서의 라우팅 신뢰도, 지연시간, 자원 사용량을 정량적으로 검증하고 결함 발생 시 즉각적인 롤백 체계 확립
- **범위 및 변경 목표**:
  - 기능 플래그(Feature Flag) 및 섀도우(Shadow) 비교:
    - 기본 라우팅은 기존 정규식 경로를 유지하면서, 백그라운드 섀도우 모드로 신규 의미 파이프라인을 병행 호출하여 동일 gold 평가셋에 대한 응답 일치도 및 성능 비교
    - 단계적 카나리(canary) 전환 체계 설계
  - 회귀 검증 전수 통과:
    - 기존 명시적 intent/filter(`profile` 빈 필터 허용 등)
    - 사용자 지정 `species_scope` (국내/전체)
    - 단일 종 사실 조회 및 이름 해소
    - 백엔드 장애 시 fallback 및 자료 부족(`insufficient_data`) 응답
  - MLflow 관측성 연동:
    - 라우팅 경로, 신뢰도 점수, 보류 사유, p50/p95 응답 지연시간, 사용 모델 버전 메트릭 로깅
    - **보안/개인정보 엄수**: 인증 정보, API 키, 불필요한 사용자 개인정보/원문은 일체 로깅하거나 저장하지 않음
  - 실제 TEST 환경 배포 및 엔드투엔드 실서버 검증:
    - 16GB Mac mini .97 (`robingraph-api-test` OrbStack) 배포 및 `manage.sh verify` 통과
    - 실제 TEST DB 및 루프백 엔드포인트(`http://127.0.0.1:8000/v1/chat`) 실측
    - 공개 TEST 서버(`robingraph-test.dove-nest.com`) Playwright Chromium PC(1280px) 및 모바일(390px) 실측
  - 정량 벤치마크 비교:
    - 임베딩 캐시 전후 호출 횟수, p50/p95 지연시간, 메모리/CPU 사용량, 에러율 비교
  - 롤백 및 안전 보장:
    - 결함 또는 성능 저하 감지 시 플래그 즉각 오프로 기존 정규식 경로 완전 복원
    - 공유 TEST Neo4j 벡터 인덱스는 테스트용으로 임의 삭제하거나 교체하지 않음
  - 운영 배포 승인 게이트:
    - TEST 배포 및 실측 검증 완료 후, 사용자 명시 승인 전에는 운영 배포를 일체 수행하지 않음
    - 구현 전 결정해야 할 신규 필드명, 실측 목표 수치 등은 기획 시점에서 '미정'으로 명시
- **예상 대상 파일 / 모듈**:
  - `src/robingraph/api/services.py` (서비스 통합 계층)
  - `src/robingraph/api/schemas.py` (응답 스키마 계약)
  - `src/robingraph/api/drf/application.py` (DRF 엔드포인트)
  - `src/robingraph/tracing.py` (관측성 로깅)
  - `tests/test_drf_parity.py` (API 패리티 검증)
  - `tests/test_graph_questions_api.py` (통합 API 테스트)
  - `docs/verification/assets/` (TEST 배포 영수증 및 브라우저 실측 자산)

  - [ ] Feature flag 기반 정규식/의미 파이프라인 섀도우 비교 체계 구축
  - [ ] 전체 Python 테스트 스위트 및 회귀 검증 100% 통과
  - [ ] MLflow 관측성 메트릭 정상 수집 및 인증 정보 배제 확인
  - [ ] TEST 컨테이너 배포 완료(`robingraph-api:test-...`, verified) 및 헬스체크 통과
  - [ ] 실제 TEST 루프백 API 및 공개 Playwright Chromium(1280px/390px) 실측 통과
  - [ ] 캐시 전후 지연시간 및 자원 사용량 벤치마크 보고서 확보
