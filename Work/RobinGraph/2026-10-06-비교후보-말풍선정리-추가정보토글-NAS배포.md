# RobinGraph 비교 후보·첫 답변 말풍선 정리와 NAS TEST 배포

일반 종 소개의 첫 말풍선은 ‘재미있는 사실’까지 읽을 수 있도록 구성하고, 비교 후보와 추가 탐색은 기본으로 접어두었다. 비교 후보는 이름·학명·점수와 작은 비교 버튼으로 정리했다. 사용자가 그림판으로 제시한 배치에 맞춰 수정했으며, 마지막 피드백은 “굿. 아주 만족이야.”였다.

같은 날 앞선 그래프 TOP3·한국어 표시명 작업은 [[2026-10-06-그래프유사종-TOP3-한국어표시명-학명보존-NAS배포]]에 기록되어 있다. 이 노트는 그 이후 UI 변경과 최종 배포를 기록한다.

## 1. 사진이 없는 경우의 기존 처리 확인

이번에는 사진 처리 코드를 변경하지 않고 현재 동작을 확인했다.

- 사용 조건이 확인된 사진이 없어도 설명과 도감 카드는 생성한다.
- 사진 영역에는 기본 새 아이콘과 “사용 조건이 확인된 대표 사진을 아직 찾지 못했습니다.”를 표시한다.
- 종 식별 불확실·복수 식별자 연결·제공처 연결 실패를 별도 상태로 구분한다.
- 제공처 연결 실패에는 ‘사진 다시 조회’, 사진 파일 로딩 실패에는 ‘사진 다시 불러오기’를 제공한다.
- 다른 종의 사진이나 AI 생성 이미지로 대체하지 않는다.
- 허용 사진은 CC0·퍼블릭 도메인·CC BY·CC BY-SA 등이며, 출처·라이선스 정보를 검증한다. CC BY 계열에는 표시 조건이 있으므로 ‘조건 없는 사진’과 구분한다.

## 2. 비교할 새를 간결한 행으로 표시

Claude에게 설계 의견과 변경 코드 리뷰를 요청하고, Codex가 Ponytail 원칙으로 기존 화면을 수정했다.

- 후보마다 테두리가 있는 한 행을 사용한다.
- 새 이름은 강조하고 학명은 보조 텍스트로 표시한다.
- 그래프 유사종에는 순위와 점수를 별도로 표시한다.
- ‘비교하기’는 작은 버튼으로 분리한다. 접근성 라벨에는 후보의 이름과 비교 정보를 유지한다.
- 이름 출처와 유사도·생태 근거는 후보 행 안의 접힌 출처 영역에 모은다.
- 분류 관련 후보와 생태 관련 후보에 같은 행 구성을 재사용한다.
- 기존 비교 요청, 로딩 표시, 재시도, 분류판 일치 검사와 별도 비교 말풍선을 유지한다.

후보 사진 조회 API나 새 라이브러리는 추가하지 않았다. 점수 검증은 기존 후보 필터를 재사용하며 유사도 가중치는 변경하지 않았다.

## 3. 그림판 시안에 맞춘 첫 답변 구성

일반 종 소개의 표시 순서를 다음과 같이 정리했다.

1. 종 이름과 기본 정보
2. 서식 환경·먹이 아이콘·IUCN 요약
3. 외관 특징
4. 생활과 먹이
5. 재미있는 사실
6. 가운데 정렬한 ‘도감 카드 보기’ 버튼
7. **기본 접힌 ‘유사도 상위 3종 살펴보기’**
8. **기본 접힌 ‘추가 정보’**
9. **기본 접힌 ‘답변 출처 보기’**

‘추가 정보’에는 다음 기존 탐색 기능을 넣었다.

- 같은 서식 환경·먹이 생태의 새 살펴보기
- 이 종의 아종 살펴보기
- 통칭·가축형 관계 알아보기

아종 응답에서는 아종 목록 대신 기존 부모 종 탐색을 유지한다. 유사종이나 생태 관련 종을 직접 질문한 경우에는 요청한 목록을 펼쳐 보여준다.

일반 소개는 응답에 이미 포함된 TOP3 자료를 보관하고, 사용자가 토글을 열 때 표시한다. 토글을 다시 열어도 같은 자료를 재사용한다. 나머지 탐색은 기존 지연 조회를 유지한다.

본문 출처를 설명 중간에서 마지막으로 이동하고, 서식 환경·먹이·IUCN 요약 출처와 기존 API citations도 마지막 출처 영역에 모았다. 특정 주제 답변의 사실 출처도 마지막 영역에서 확인할 수 있도록 했다. 본문 전체를 출처 영역으로 숨긴 변경은 아니다.

## 4. 검증

- 프런트엔드 테스트 **125개 모두 통과**.
- 본문 순서, ‘재미있는 사실’ 뒤 카드 버튼, 접힌 TOP3·추가 정보, 마지막 출처 영역을 검사했다.
- 본문 네 섹션·IUCN 요약·API citations의 출처가 마지막 영역에 유지되는 것을 검사했다.
- TOP3 열기·닫기·다시 열기와 기존 독립 비교 말풍선·두 카드 기능을 확인했다.
- 첫 표시에서 탐색 API를 추가 호출하지 않는 것과 사전 조회 TOP3 재사용을 확인했다.
- 기존 직접 생태 질문, 지연 응답·대화 초기화, 분류판 불일치 및 안전한 링크 검사를 포함한 회귀 테스트가 통과했다.
- `git diff --check` 통과, `graphify update .`로 AST 그래프 갱신 완료.
- NAS 공개 `/chat`, `/health` 정상 응답. 배포된 JS·CSS의 SHA-256이 로컬 변경 파일과 일치했고 HTML의 캐시 버전도 확인했다.
- 첫 UI 배포 후 실제 청둥오리 유사종 조회에서 고방오리·안데스청둥오리·흰뺨고방오리 3종과 각 100점을 확인했다.

이번 UI 변경에서 Python 전체 테스트나 Chromium 화면 검증을 새로 실행한 것은 아니다. 자동 DOM 테스트·배포 파일 해시·서비스 응답 검증과 사용자의 화면 확인을 구분한다.
