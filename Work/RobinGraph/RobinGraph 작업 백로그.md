## 다음 작업

### RG-001 — MLflow 자동 로깅 연동

- [ ] 진행 및 완료
- **목적**: 질문부터 검색·모델 호출·답변까지의 실행 과정, 단계별 지연과 오류를 MLflow에서 확인한다.
- **범위**:
  - NAS MLflow 서버의 버전·접속 주소·인증과 현재 패키지의 호환성을 확인한다.
  - 로컬 `.env`, NAS `.env.nas.test`와 `.env.nas.prod`에 서버 주소·실험 이름 등 필요한 설정을 연결한다.
  - MLflow 패키지와 앱 시작 시 자동 로깅 초기화를 추가한다. 환경 변수만 넣는 것으로는 활성화되지 않는다.
  - 기존 LangChain 흐름을 자동 추적하고, Gemini 호출을 지원되는 연동으로 연결한다.
  - Neo4j의 기존 Cypher·활성 분류판·출처 제한을 유지하면서 조회 단계를 구분한다.
  - Jina의 512차원과 질문·문서 작업 구분을 유지한다. 자동 추적에서 빠지는 정보만 추가 계측한다.
  - 검색·모델 호출을 전체 요청의 하위 단계로 연결한다.
- **완료 기준**:
  - NAS TEST에서 실제 질문을 보내 MLflow의 **Traces** 화면에 하나의 연결된 실행 과정이 나타난다.
  - 검색과 모델 호출의 입력·출력, 소요 시간, 오류가 의도한 범위에서 확인된다.
  - 제공되는 모델·토큰 정보를 확인하고, 기록되지 않는 항목은 구분해 문서화한다.
  - 기존 종 조회·근거 답변 동작을 테스트하고 설정 방법을 기록한다.
- **지시 예시**: “Obsidian의 RobinGraph 백로그에서 RG-001 MLflow 작업을 진행해줘.”
