### RG-602 — MLflow에서 답변 결과와 미응답 사유 구분

- [x] 구현·회귀·독립 검토·실제 NAS TEST 검증 완료 (2026-10-08)
- **우선순위**: 완료 — 당시 착수 우선순위 2.
- **목적·신고 사례**: MLflow에서 “박새에 대해 알고 싶어” 요청이 “입력한 이름의 종 정보를 확인하지 못했습니다.”와 “활성 분류 개념집합에서 일치 항목을 찾지 못했습니다.”로 끝나는 경우를 정상 답변과 구분해 찾는다. 사용자가 제공한 화면은 `kind=profile`, `profile=null`이다. 이것만으로 박새 데이터 자체가 없는지, 이름 해소·활성 분류 연결이 실패했는지는 단정하지 않는다.
- **현재 근거**: `_traced_route`는 `selected_intent/route_method/disposition`을 span attribute로 기록하지만, 미응답 사유 코드와 Trace 목록 필터용 태그는 명시적으로 제공하지 않는다. 종 미발견 분기는 `disposition=abstain`을 반환한다. HTTP 성공·Trace 실행 상태와 사용자에게 유효한 답변을 제공했는지는 서로 다른 기준이다.
- **변경 전후 목표**: 응답 본문을 일일이 펼쳐 확인하던 상태에서 Trace 목록에서 결과·사유별로 검색하고 상세에서 어느 단계가 막혔는지 확인할 수 있게 한다.
- **범위·구현 단계**:
  1. 응답 결과를 정상 답변(`answer`), 추가 확인(`clarify`), 답변 보류(`abstain`), 실행 오류(`error`)로 구분하고 실패/보류 사유를 별도 구조화한다. 정상적인 자료 없음 응답을 무조건 기술적 ERROR로 바꾸지 않는다.
  2. 사유 코드 초안은 `taxon_not_found`(활성 분류에서 이름 미해소), `intent_uncertain`, `ambiguous_name`, `filter_mismatch`, `evidence_not_found`, `observations_empty`, `handler_unavailable`, `upstream_error`, `unsupported_question`, `unknown`으로 두고 실제 분기에 맞게 확정한다. 사용자에게 보이는 한국어 문장으로 코드를 역추정하지 않고 발생 지점에서 기록한다. `upstream_error`와 조회기 미설정을 구분할 수 있도록 현재 예외 분기도 살핀다.
  3. Trace tag 후보 `response_disposition`, `response_reason`, `failure_stage`, `selected_intent`, `route_method`를 정의한다. 이름 해소·검색·생성·인용 검증 중 실패 단계를 기록하고 필요시 원인·검색 건수를 상세 span에도 남긴다. 성공 응답의 reason은 `none`, 미확인 사유는 `unknown`처럼 일관된 값을 사용한다.
  4. 현 MLflow 서버/SDK 버전에서 Trace tags 검색과 UI 표시를 확인한다. span attribute를 추가하는 것만으로 Trace 목록 필터 기능 완료라 하지 않는다. [Trace tags 공식 문서](https://www.mlflow.org/docs/latest/genai/tracing/attach-tags/), [Trace 검색 공식 문서](https://www.mlflow.org/docs/latest/genai/tracing/search-traces)
  5. 정상·보류·추가 확인·오류의 필터 예제와 사용법을 작성한다. 예: `tags.response_reason = 'taxon_not_found'`, `tags.response_disposition = 'abstain'`. 목록에서 이유를 읽을 수 있는 태그/열 표시 또는 상세 요약을 지원하고, 실제 버전에서 가능한 표시 방법을 기록한다.
  6. tracing 비활성·MLflow 장애에도 원래 API 응답은 유지한다. 키·인증 헤더·민감 값을 태그에 기록하지 않는다. 기존 trace는 새 필드가 없는 과거 기록으로 구별하고, 자동 소급 수정하지 않는다.
- **예상 변경 위치**: `src/robingraph/api/app.py`, `src/robingraph/tracing.py`, 필요시 응답/예외 사유 모델, `tests/test_mlflow_tracing.py`, `docs/mlflow-tracing.md`, 실제 trace 검증기.
