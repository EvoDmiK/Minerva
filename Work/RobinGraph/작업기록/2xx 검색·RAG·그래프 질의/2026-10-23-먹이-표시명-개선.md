## 1. 배경 및 사용자 요구사항 분석

### 1) 사용자 인입 및 이전 작업 오해 정정
- **인입 배경**: 2026-10-23 사용자로부터 어제 요청되었던 먹이 표시명 변경(`무척추동물 ➔ 곤충`, `척추동물 ➔ 고기`)이 누락되었다는 피드백 인입.
- **이전 작업(RG-209)의 의도 오해 분석**:
  - 사용자 TEST 화면에서 "까마귀과 중에서 곤충을 먹는 새는?" 질의가 clarify 처리된 것에 대해, 초기 분석팀은 "데이터베이스에 곤충(Insect) 단위 데이터가 없으므로 곤충을 질의할 수 없다고 안내해야 한다"고 판단함.
  - 그리하여 RG-209에서는 `unsupported_food_answer`를 통해 "자료에 곤충이 없으니 무척추동물로 질문해 주세요"라는 대체 안내를 구축했음.
  - 그러나 이는 사용자의 실제 의도와 상반된 과도기적 조치였음. 사용자가 진정 원했던 것은 **일반 대중과 사용자가 흔히 사용하는 단어인 '곤충'과 '고기'를 직관적인 대표 표시명으로 제공하되, 원천 데이터의 학술적 범주(무척추동물, 척추동물 3종)를 보존**하는 것이었음.
- **방향성 정립**:
  - RG-209 문서는 당시의 의사결정 및 검증 이력으로서 보존하고 후속 링크를 추가.
  - 본 작업(RG-210)을 통해 원천 데이터 구조를 건드리지 않으면서, 표시명(display alias)과 질의 해석 계층에서 '곤충'과 '고기'를 정규 지원하도록 전면 개선.

### 2) 데이터 및 생물학적 정합성 가드레일
1. **원천 데이터 무변경 보존**:
   - EltonTraits 및 AVONET의 원천 키(`invertebrate`, `endotherm_vertebrate`, `ectotherm_vertebrate`, `unknown_vertebrate`, `fish`, `carrion` 등)는 DB와 내부 파이프라인에서 100% 그대로 유지.
2. **곤충 (원자료: 무척추동물)**:
   - `invertebrate`의 한국어 대표 표시명을 `곤충 (원자료: 무척추동물)`로 정의.
   - 단축어는 `곤충`으로 처리하여 `"까마귀과 중에서 곤충을 먹는 새는?"` 질의 시 `invertebrate > 0` 조건으로 직접 매핑.
   - 동시에 화면 안내 및 limitation에 *"원자료 범주는 ‘무척추동물’로, 곤충이 아닌 무척추동물(거미, 지렁이, 달팽이 등)을 먹는 경우도 포함합니다"*라는 설명을 병기하여 학술적 왜곡 방지.
3. **고기 (원자료: 척추동물 성분 합계)**:
   - `고기`는 3개 척추동물 성분(`endotherm_vertebrate` + `ectotherm_vertebrate` + `unknown_vertebrate`)의 합산(`meat`)으로 정의.
   - `물고기(fish)`와 `사체(carrion)`는 육류와 생태적 특성이 구별되므로 별도의 독립 먹이 범주로 유지.
4. **양방향 동의어 검색 보존**:
   - 사용자가 새로운 대표 명칭(`곤충`, `고기`)으로 묻든, 기존 원천 학술 명칭(`무척추동물`, `척추동물`)으로 묻든 동일한 조건으로 정확히 해석되어야 함.
