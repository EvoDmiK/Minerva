> 실제 TEST API 재현 결과, "까마귀과 중에서/중 곤충을 먹는 새는?"은 모두 clarify 처리된 반면, 상위 범주인 "까마귀과 중 무척추동물을 먹는 새는?"은 135개 스코프 중 100개 평가 가능, 98개 일치로 정상 응답을 반환했다.  
> 원인 분석 결과 `graph_condition_extractor.py`의 `_UNSUPPORTED` 규칙에서 `곤충`이 `food other`로 차단되어 있었으며, 실제 활성 TEST DB 실사 결과 그래프에는 "곤충(Insect)" 전용 claim/출처가 없고 상위 개념인 `invertebrate`/`Invertivore`(무척추동물)만 존재함이 확인되었다.  
> 곤충은 무척추동물의 하위 분류군(거미·지렁이·달팽이 등 제외)이므로 **"곤충 = 무척추동물"로 임의 치환하는 것은 생물학적 정확성에 위배**된다. 따라서 현재 자료로 정확한 곤충 섭식 목록을 단정할 수 없음을 투명하게 안내하고, 상위 범주인 "무척추동물을 먹는 새" 등으로 대체 검색할 수 있도록 구조화된 안내를 제공하는 최소 구조 개선을 추진한다.

## 1. 문제 분석 및 실제 API 재현 검증

### 1) 사용자 인입 증상
- 2026-10-23 사용자 모바일 환경(TEST 웹)에서 다음 질문 입력:
  > *"까마귀과 중에서 곤충을 먹는 새는?"*
- **응답 증상**: 구체적인 조류 목록이나 명확한 안내 없이 단순 clarify("질문에 조건을 추가해 주세요") 류의 일반 응답 반환.

### 2) 실제 TEST API 대조 재현
- **검증 환경**: `https://robingraph-test.dove-nest.com` (Image: `robingraph-api:test-taxonomic-traits-eb8169862c0e`)
- **재현 질의 1**: `"까마귀과 중에서 곤충을 먹는 새는?"` ➔ `clarify` (동일)
- **재현 질의 2**: `"까마귀과 중 곤충을 먹는 새는?"` ➔ `clarify` (동일)
- **대조 질의 3**: `"까마귀과 중 무척추동물을 먹는 새는?"`
  - `status`: `answer`
  - `coverage`: `scoped: 135`, `evaluable: 100`, `matched: 98`
  - 정상 조류 카드 및 목록 반환 확인.

### 3) 코드 원인 분석 (`graph_condition_extractor.py`)
```python
_UNSUPPORTED = (
    ('co_occurrence', r'같은\s*곳에서\s*(?:공존하는|공존|사는)|...'),
    ...
    # Foods with no composition key in the data (곤충 is not 무척추동물); 물고기/씨앗/꽃꿀 are data keys now.
    ('other', r'(?<![가-힣])(?:곤충|벌레|어류|곡식|곡물|꿀|육류|고기|잎)(?:을|를)?(?=\s*먹)'),
    ...
)
```
- 파서가 `곤충`을 `_UNSUPPORTED` 규칙으로 분류하여 질의 추출에서 제외하고, 일반적인 의도 불충분 메시지만 내보내고 있었음.

## 2. 데이터 실사 결과 및 설계 원칙

### 1) 활성 TEST DB 실사 결과 (Claude 확인)
- 활성 TEST Neo4j 및 PostgreSQL 데이터 실사:
  - 그래프에 존재하는 먹이 관련 형질은 AVONET의 `trophic_niche` (`Invertivore`, `Vertivore` 등) 및 EltonTraits의 `diet_distribution` (`invertebrate`, `endotherm_vertebrate`, `fish` 등 10개 키)으로 구성됨.
  - **"곤충(Insect)" 전용 claim, 속성 또는 원천 문헌 근거는 DB에 전혀 존재하지 않음.**

### 2) 생물학적 정합성 원칙 (엄격 준수)
- **곤충 = 무척추동물 강제 치환 금지**:
  - 생물학적으로 무척추동물(Invertebrate)은 곤충뿐만 아니라 거미류, 갑각류, 환형동물(지렁이), 연체동물(달팽이) 등을 포괄함.
  - 무척추동물을 먹는 조류를 '곤충을 먹는 새'로 임의 매핑하여 답변하면, 실제로는 지렁이나 달팽이를 주로 먹는 조류까지 곤충식 조류로 단정하는 **학술적 왜곡 및 환각(Hallucination)**이 발생함.
  - 따라서 조류 데이터 거버넌스 원칙에 따라 임의 치환을 일체 금지함.

### 3) 개선 설계: 자료 한계 명시 + 대체 질문 가이드
- 사용자가 "곤충을 먹는 새"를 물었을 때, 시스템이 침묵하거나 단순 오류를 내는 대신:
  1. **자료 한계 설명**: 현재 제공되는 생태 데이터베이스(AVONET / EltonTraits)에는 '곤충' 세부 단위 자료가 포함되어 있지 않음을 친절히 안내.
  2. **대체 질문 제시**: 상위 분류 범위인 **"무척추동물을 먹는 새"**로 질문하면 검색이 가능함을 명시적이고 클릭/복사 가능한 형태로 유도.
