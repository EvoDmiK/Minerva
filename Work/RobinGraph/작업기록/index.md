## 문서 관리

- 작업 상세는 각 폴더의 `작업 백로그.md`에 작성한다.
- 실제 작업기록은 같은 카테고리 폴더에 저장하고 해당 백로그의 작업기록 목록에 링크한다.
- 새 작업 등록·상태 변경 시 전체 백로그의 현황표도 갱신한다.
- 별도 검토·감사·설계 문서는 [[Work/RobinGraph/검토자료/index|검토자료]]에서 관리한다.
- 파일명과 과거 ID·검증·배포 이력은 보존하고 이동 시 연결 링크를 갱신한다.
