### RG-406 — 한국 서식 여부 토글과 범위별 이름 우선 정책

- [ ] 후속 계획 — 등록만 완료 (2026-10-08), 구현 미착수.
- **우선순위**: 5 — 기존 신규 대기 RG-602 → RG-405 → RG-202 뒤의 후속 작업. 실제 착수 시점은 사용자 지시를 따른다. 최후순위 보류 RG-102·RG-503·RG-504·RG-505는 유지한다.
- **요청 배경·목표**: 사용자가 “나중에 한국 서식종하고 안 사는 종을 토글로 나눠, 한국에 서식하는 종 검색은 한국어 우선, 안 사는 종은 영어 우선”을 제안했다. 현재 TOP3는 지역 구분 없이 검증 국명 후보를 먼저 선정하므로, 향후 검색 범위에 따라 후보 집합과 이름 우선 정책을 함께 바꾼다.
- **현재 근거·주의점**: 검증 국명이 있다는 사실은 한국 서식 근거가 아니다. 국명 없음·국내 관찰 기록 없음도 한국 비서식의 증거로 취급하지 않는다. 현재 국명 사전이나 사진·영어 이름만으로 국내 서식 여부를 판정하지 않는다. 이 작업 등록 중 서식 자료 조사나 실제 데이터 검증은 수행하지 않았다.
- **변경 전후 동작**:
  - 현재: 지역 토글 없이 전체 활성 종 중 검증 국명이 있는 후보를 우선하고 같은 이름 조건 안에서 점수순 추천한다.
  - 예정 한국 서식종 모드: 근거로 확인된 한국 서식종 집합에서 검색·비교 후보를 고른다. 검증된 국명을 우선 선정·표시하고 같은 조건 안에서 기존 가중 점수순으로 정렬한다.
  - 예정 한국 비서식종 모드: 비서식으로 확인된 집합에서 검색·비교 후보를 고른다. 원자료의 영어 이름을 우선 선정·표시하고 같은 조건 안에서 기존 가중 점수순으로 정렬한다. 국명이 있는 해외 종도 이 모드에서는 영어 이름을 우선한다.
  - 이름이 없으면 확인 가능한 다른 언어 이름, 최종적으로 학명을 사용한다. 학명·이름 출처·서식 범위 근거는 함께 보존한다.
  - 한국 서식 여부 미확인은 별도 상태로 관리한다. 단순한 국내 목록 미등재를 비서식으로 단정하거나 미확인 종을 비서식 목록에 자동 포함하지 않는다. 미확인 표시 위치·전체 검색 기본값은 착수 시 확정한다.
- **범위·구현 단계**:
  1. 한국 서식 여부를 판별할 사용 가능한 원자료·이용 조건·갱신 주기·분류판을 확인한다. 텃새·여름/겨울철새·나그네새·미조의 포함 기준을 자료에 맞춰 명시하고, “서식종”과 “국내 기록종”을 구분한다.
  2. 원자료의 종을 활성 분류판 종 ID·학명으로 연결하고 서식/비서식/미확인 상태, 출처·판정 기준·자료 버전을 보존한다. 분류 변경·누락·충돌은 임의 확정하지 않는다.
  3. 검색 화면에 한국 서식종/그 외 종을 고르는 토글을 제공하고 실제 후보 검색 범위에 연결한다. 화면 이름만 바꾸고 후보 집합은 전체로 남기는 구현을 피한다. 최종 사용자용 모드명은 미확인 처리 기준과 함께 정한다.
  4. 선택한 범위의 이름 우선 정책을 일반 검색·TOP3·같은 속/과·생태 관계·비교 카드에 일관되게 전달한다. 현재 점수 계산과 출처 검증은 유지하고, 이름 우선순위와 추천 순서를 화면에 설명한다.
  5. 국명/영어 이름 검증과 부족한 이름 후보의 대체 표시, 3종 미만인 후보 집합을 처리한다. 선택 범위 밖의 종으로 추천 수를 억지로 채우지 않는다.
  6. 토글 변경 시 이전 요청의 늦은 응답과 이전 범위의 비교 결과가 새 범위에 섞이지 않도록 상태·취소·재조회 동작을 정의한다.
- **예상 변경 위치**: 한국 서식 상태·근거/분류판 연결 데이터, 검색/API 범위 계약, 이름 우선 정책·후보 조회기, 채팅 토글·비교 화면, 관련 회귀 테스트·작업 문서. 구체 파일은 착수 시 코드·자료 검토로 확정한다.
- **협업 추천**:
  - **Codex 주 담당**: 자료·활성 분류 연결, 범위 API·후보 선정·이름 정책, 회귀·통합 검증.
  - **Claude 협업**: 토글·모드 설명·이름/출처 표시와 모바일 화면·상태 전환 UX.
  - **Antigravity 독립 검증**: 국내 서식 근거·계절/미조 기준·미확인 처리 대조, 실제 API·브라우저 범위 검증.
  - 추천이며 아직 위임하거나 실행하지 않았다. 실행 시 사용 가능한 설정 모델을 확인한다.
- **완료 기준·검증 계획**:
  - 한국 서식종 모드는 확인된 국내 집합만 반환하고 국명이 우선된다. 비서식종 모드에서는 확인된 해외 집합만 반환하고 영어 이름이 우선된다.
  - 한국어 이름이 있는 해외 종, 국명이 없는 국내 종, 서식 여부 미확인 종을 각각 검증해 이름 유무와 서식 판정을 혼동하지 않는다.
  - 철새·나그네새·미조·자료 충돌·분류판 불일치의 포함/미확인 동작이 정의된 기준과 일치한다.
  - 동일 후보의 점수는 모드의 이름 정책 때문에 변하지 않고, 후보 범위와 추천 순서·표시 언어만 정책대로 달라진다. 근거·학명·영어/국명 대체 표시를 보존한다.
  - 토글 연속 변경·느린 이전 응답·비교 클릭·빈 집합·3종 미만·모바일/키보드 조작을 검증한다. 모의 테스트와 실제 자료/API 검증을 구분한다.
- **등록 검증·커밋·배포**: 이번에는 Obsidian 백로그의 상세·목차·현황·변경 이력만 추가하고 저장 결과를 재조회한다. 애플리케이션 테스트·실제 서식 자료 검증·구현·NAS 배포는 수행하지 않았다. 저장소 변경이 없어 Git 커밋·push는 해당하지 않는다. 현재 NAS TEST `f0fed63`의 동작은 직전 완료 기록을 따른다.
