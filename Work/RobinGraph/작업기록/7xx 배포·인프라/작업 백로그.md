- main 워크트리(브랜치 dev-agy)의 제품명은 Antigravity지만 RG-701에서는 Codex를 계획 에이전트로 둔다. 기존 UI 역할 범위는 유지한다. 이는 RG-701 한정 선택이며 공통 AGENTS.md나 실행 중 세션 설정을 바꾸지 않는다.
- 이번 배정으로 구현·다른 에이전트 기동·서비스·DB·배포·commit/push를 시작하지 않았다.
