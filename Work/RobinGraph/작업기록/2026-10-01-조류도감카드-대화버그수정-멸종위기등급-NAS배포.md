## 카드와 채팅 UI

### 앞면과 뒷면

앞면에는 종의 한국어 이름과 학명, 서식 환경 문양, 적색목록 등급, 사진, 핵심 특성을 표시한다. 핵심 특성은 체중·먹이 유형·서식 환경·주 생활 방식 중 확인된 값으로 구성한다.

`출처 보기 ↻`를 누르면 뒷면으로 전환한다. 뒷면에는 전체 특성, 사진 제공처·촬영자·라이선스, 분류 정보와 등급 출처를 담았다. 출처는 토글로 펼치고 접을 수 있으며, `앞면 보기 ↻`로 돌아온다.

카드는 닫기 버튼과 Escape 키로 닫을 수 있다. 다시 열면 앞면부터 표시된다. 좁은 모바일 화면에서 닫기 버튼과 문양이 겹치던 부분도 간격을 조정했다.

### 사진과 한국어 표시

사진은 한 번에 한 장씩 보여준다. `이전 사진`·`다음 사진` 버튼으로 이동하고 현재 번호를 표시한다. 양 끝에서는 해당 이동 버튼을 비활성화한다.

원본 데이터 값은 보존하고 화면에 쓰는 표시 값을 한국어로 변환한다. 예를 들어 `Forest → 숲`, `Wetland → 습지`, `Generalist → 다양한 생활 방식`, `Omnivore → 잡식`으로 표시한다.

다음 11개 원본 서식 환경에 각각 다른 SVG 문양과 색상을 적용했다.

## 멸종 위험 등급과 카드 색상

카드 색상은 활성 AviList 분류 자료에 저장된 IUCN 적색목록 코드를 기준으로 결정한다. 현재 IUCN 서버를 실시간 조회한 평가라고 표시하지 않으며, 뒷면에서 자료의 출처 링크와 릴리스 버전을 확인할 수 있다.

| 코드 | 한국어 등급 | 카드 표현 |
| --- | --- | --- |
| LC | 관심대상 | 초록 |
| NT | 준위협 | 은색·청록 |
| VU | 취약 | 금색 |
| EN | 위기 | 구리색 광택 |
| CR | 위급 | 분홍·진홍색 광택 테두리 |
| EW | 야생절멸 | 보라색 광택 테두리 |
| EX | 절멸 | 어두운 색과 광택 테두리 |
| DD | 정보부족 | 중립 회색 |
| NE | 미평가 | 중립 회색 |
| 누락·잘못된 코드·출처 미확인 | 미확인 | 중립 회색 |

위협 등급에 따라 수집형 카드의 시각적 강조를 높였다. 적색목록 등급을 특정 지역의 실제 관찰 빈도나 개체 수로 해석하지 않도록 뒷면에 설명을 추가했다. DD와 NE는 낮은 위험으로 처리하지 않는다. 광택 애니메이션은 움직임 감소 설정을 존중한다.

`CR (PE)`와 `CR (PEW)`는 색상을 CR로 정규화하되 원본 표기를 보존한다. 앞면과 채팅에는 각각 `절멸 가능성`과 `야생절멸 가능성`을 표시하고, 뒷면에서도 원본 등급을 확인할 수 있다.

자료 조회는 해결된 종의 개념집합과 분류 릴리스에 고정한다. 출처·릴리스·URL이 확인되지 않거나 조회가 실패하면 미확인 상태로 표시한다. 사진·특성·보전 정보 중 한 제공처의 실패가 다른 결과까지 막지 않도록 분리했다.

- 실제 검증된 등급 출처: [AviList v2025b 스냅샷](https://explore.avilist.org/data/avilist-2025b.json)
- 등급과 PE·PEW 표기 참고: [IUCN Red List FAQ](https://nrl.iucnredlist.org/about/faqs)

## 짧은 종 설명

설명은 출처가 있는 서식 환경·생활 방식·먹이·체중 필드만 사용한다. 확인하지 않은 생태나 개체 수를 추측해 덧붙이지 않는다. 자료가 없을 때는 확인하지 못했다는 안내를 표시한다.

NAS TEST에서 대륙검은지빠귀를 질문해 다음 답변을 확인했다.

> 대륙검은지빠귀의 서식 환경은 숲이며, 주 생활 방식은 다양한 생활 방식입니다. 먹이 정보는 ‘잡식’입니다. 체중은 102.73 g입니다.

카드에는 숲 문양과 `관심대상 (LC)` 등급이 표시됐다. 채팅의 설명과 프로필의 요약 값이 같은지도 확인했다.

## 연속 질문 버그 수정

첫 답변을 표시할 때 빈 대화 안내 노드가 제거된다. 다음 질문에서는 이미 제거된 노드를 다시 삭제하려 하면서 DOM 오류가 발생했다.

빈 안내 노드가 실제로 대화 목록의 자식인지 확인한 뒤 제거하도록 수정했다. 프런트엔드 테스트의 가상 DOM도 부모 관계와 삭제 오류를 반영하도록 보완해 회귀 검증을 추가했다.

검증한 흐름:

1. 추천 질문 버튼으로 첫 질문 전송.
2. 대화를 지우지 않고 보내기 버튼으로 두 번째 질문 전송.
3. Enter로 세 번째 질문 전송.
4. 대화 지우기 후 다시 질문.
5. 각 단계의 요청·답변 수와 JavaScript 오류 확인.

로컬과 NAS TEST에서 모두 정상 동작했고 JavaScript 오류는 없었다.

최초 기록 이후 아래 변경을 완료했다. 기능 변경은 GitHub 기본 브랜치에 반영했으며, 현재 카드 배포는 `da6739a-card-flip-20261001` 빌드다. TEST·PROD의 이미지 ID는 `c2bac3d56524`로 시작한다. 실제 종 기능은 TEST에서 검증하고 PROD는 상태와 정적 파일을 검증했다.

### 구조화된 설명과 그래프 관계 탐색

- 설명창에 기본 정보, 외관적 특징, 생태, 재미있는 사실을 자료와 출처를 바탕으로 표시한다.
- 같은 속·과의 다른 새를 찾아 비교하는 기능을 추가했다. 탐색·비교는 카드 안이 아니라 설명창에 배치했다.
- 비교 결과에는 특성과 출처·자료 버전을 표시한다.
- 같은 속·과 관계를 진화적 거리나 가장 가까운 종으로 해석하지 않는다.
- 관련 목록은 한국어 이름이 확인된 종만 이름순으로 최대 12종씩 표시하며, DB에서 이름을 먼저 필터링한 뒤 제한한다.

### 한국어·영어 이름 표시

종 제목은 한국어 이름을 우선한다. 한국어 이름이 없으면 활성 AviList 자료의 영어 이름을 표시하고, 학명은 별도로 유지한다. 예를 들어 `Anas albogularis`는 `Andaman Teal`로 표시된다. 영어 이름을 임의로 한국어로 번역하거나 새로운 검색 별칭을 생성하지 않는다.

### 흰뺨검둥오리 검색 복구

원본 Wikidata 스냅샷에서 `Anas zonorhyncha`(Q1268169)와 `Anas poecilorhyncha`(Q839542)에 모두 ‘흰뺨검둥오리’가 붙어 있었다. 기존 동명 충돌 검사가 두 이름을 보류하면서 한국어 조회가 404를 반환했다.

[새와 생명의 터 2024 조류목록](https://www.birdskoreablog.org/wp-content/uploads/2024/08/Birds-Korea-checklist-Kor-2024-final-with-quick-fix-20240827.pdf)과 활성 AviList 자료를 대조해 이름을 `Anas zonorhyncha`에 연결했다. 다른 종인 Indian Spot-billed Duck에는 해당 국명을 붙이지 않았다.

- 검토 근거와 정확한 원본 조합: `config/korean-name-reviews.json`
- 기존 활성 스냅샷 보정: `scripts/repair_reviewed_korean_names.py` (기본 dry run, `--apply`로 적용)
- 기존 보류 후보와 원본 근거는 보존하고 검토 결과·근거 URL을 기록했다.
- 두 번 적용해 중복 이름이 늘지 않는 것을 확인했다.
- 다음 수집에서는 검토한 잘못된 원본 조합만 보류하고 나머지 동명 충돌 검사는 유지한다.
- 검토 규칙이 적용되는 새 스냅샷의 dataset/release ID에는 검토 규칙 해시를 추가해 기존 보류 노드와 섞이지 않게 했다.
- NAS canonical n8n workflow에는 정규화 함수·검토 목록·스냅샷 식별자 계산만 반영했다. 다른 노드·설정과 비활성 상태를 유지하고 API 재조회 및 분류 함수 실행으로 확인했다. 전체 수집 workflow를 실행해 검증한 것은 아니다.

실제 TEST에서 흰뺨검둥오리 검색·설명·카드 제목과 학명 연결이 정상 동작했고, 청둥오리의 같은 속 목록에도 나타나는 것을 확인했다.

### 입체 카드 뒤집기 효과

‘출처 보기 ↻’를 누르면 은색 테두리를 포함한 전체 카드가 입체적으로 회전한다. 카드가 옆면을 향하는 순간 앞뒤 내용을 바꾸고, 빛이 스친 뒤 작은 반동을 주며 멈춘다. 앞면으로 돌아갈 때는 회전 방향이 반대다.

- 전환 시간: 660ms (앞쪽 회전 270ms + 뒷면 펼침 390ms)
- Web Animations API로 원근감·회전·기울기·크기를 제어한다.
- CSS 빛 반사 효과는 전환 중에만 표시한다.
- 연속 클릭은 전환 중 무시해 상태가 꼬이지 않게 했다.
- 전환 도중 닫으면 애니메이션을 취소한다. 다시 열면 앞면이며 이전 콜백이 다시 뒤집지 않는다.
- 움직임 줄이기 설정이나 애니메이션 API 미지원 환경에서는 즉시 앞뒤를 전환한다.
- 변경 파일: `src/robingraph/api/static/chat.js`, `styles.css`, `tests/frontend/chat_ui.test.js`

## 상세 보완 — 2026-10-05

### 설명창과 카드의 역할

설명창은 기본 정보·외관·생태·재미있는 사실과 그래프 탐색을 제공한다. 카드는 핵심 정보를 간결하게 보여주고 사진·앞뒤 전환·출처 확인을 담당한다. 이후 같은 속·과, 통칭·가축형, 아종, 생태 범주의 탐색도 설명창에서 제공하도록 확장했다.

| 표시 요소 | 결정 근거 | 결측 시 표시 원칙 |
|---|---|---|
| 서식 환경 문양 | 출처가 있는 habitat | 환경을 추측해 문양을 부여하지 않음 |
| 카드 색·광택 | 활성 분류 자료의 보전 등급 | 미확인 상태로 표시 |
| 먹이 아이콘 | 확인된 구성비 또는 자료의 범주 | 없는 먹이를 임의로 추가하지 않음 |
| 사진 | 정확한 분류군 매핑과 파일별 사용 조건 | 설명·카드를 유지하고 사진 상태 안내 |

보전 등급에 따른 카드 연출은 위험도를 시각적으로 구분하는 디자인이다. 카드의 연출을 실제 개체 수나 관찰 확률에 대한 측정값으로 해석하지 않는다.

### 연속 질문과 카드 동작의 회귀 확인

첫 답변 이후 대화를 지우지 않고 둘째 질문을 보내도 입력과 답변이 계속 동작해야 한다. 비교 요청 중 대화 지우기, 사진 조회 지연, 카드 닫기·다시 열기에서도 이전 응답이 새 대화에 섞이지 않아야 한다.

카드 뒤집기는 출처를 읽을 수 있는 상태까지 확인하며, 사진이 없을 때도 앞뒤 전환과 설명이 동작해야 한다. 움직임을 줄이는 사용자 설정과 연속 클릭 처리도 기존 검증 범위에 포함한다.
