# 그래프 검색 기반 아종·통칭 카드

요청한 아종·통칭 카드 연결을 구현하고 NAS TEST에 배포했다. RG-005~RG-009와는 독립적으로 기록하며, 다른 백로그 항목의 완료 상태를 이 결과만으로 변경하지 않는다.

## 구현

- 통칭의 검토된 그래프 대상이 한 종이면 설명과 카드 버튼을 자동 준비한다. 여러 종이면 후보를 선택한다. 후보·출처·관계 설명을 유지한다.
- 종 설명창의 **이 종의 아종 살펴보기**는 활성 Neo4j `PARENT_OF` 관계로 아종을 조회한다. 선택한 아종의 설명과 별도 카드를 제공한다.
- 아종 학명의 직접 질문과 소속 종 자료 조회를 지원한다. 계통은 목→과→속→종→아종으로 표시한다.
- 카드에는 **아종**, 소속 종과 확인된 분포 설명을 표시한다. 부모 종 형질은 별도 **종 수준 참고 정보**에 모으며 아종의 사진·체중·먹이·서식지·보전 등급으로 대체하지 않는다.
- 사진은 정확한 아종 학명·아종 rank 매핑과 파일별 사용 조건을 확인한다. 아종 보전 상태는 별도 검토 자료가 없어 미확인·중립 색상으로 표시한다.
- 우선 청둥오리 아종 두 개의 분포 차이를 한국어로 요약했다. 고정 개념집합·릴리스·taxon ID·학명·원문이 일치할 때만 사용한다. 분포 설명이며 외관을 구별할 수 있다는 주장이 아니다. 다른 아종의 외관·한국어 분포 설명은 미검토임을 안내한다.
- 아종·부모 관계와 분류군을 활성 릴리스·허용 정책으로 제한하며, 화면에서도 taxon ID·분류판 일치와 대화 초기화 이후 늦은 응답을 검사한다.

## 데이터 수집 방식

NAS TEST에는 기존 n8n AviList 분류 수집으로 아종 19,879개와 부모 관계가 이미 적재되어 있었다. 이번에는 이를 조회하며 DB를 변경하지 않았다. 형질은 기존 n8n EltonTraits·AVONET 자료, 통칭은 검토 manifest 적재 스크립트, 사진은 요청 시 API를 사용한다. 한국어 분포 요약은 출처를 검토한 코드 기록이다. 새 n8n 수집 워크플로를 추가하지 않았다.

## 상세 보완 — 2026-10-05

### 실제 그래프 관계로 카드를 여는 과정

1. 종 질문을 활성 AviList 개념집합에서 해석한다.
2. 설명창에서 아종 탐색을 요청하면 해당 species의 PARENT_OF 관계를 조회한다.
3. 승인된 같은 릴리스의 subspecies 후보를 반환한다.
4. 후보를 선택하면 정확한 아종 프로필을 조회하고 taxon ID·분류판을 다시 확인한다.
5. 아종 설명과 카드 버튼을 준비하며 필요하면 소속 종 자료를 별도로 조회한다.

API는 `/v1/taxa/subspecies`에서 후보·출처·분류판·한도 초과 여부를 반환한다. `/v1/taxa/profile`은 종과 아종 프로필을 지원한다. 학명이 세 단어라는 이유만으로 실제 부모 관계를 만들어내지 않는다.

### 아종 자료와 부모 종 참고 자료

| 항목 | 아종 직접 자료 | 부모 종 자료 |
|---|---|---|
| 형질 | traits | reference_traits로 분리 |
| 표시 위치 | 아종 설명·카드에 해당 출처와 표시 | 카드 뒷면 ‘종 수준 참고 정보’ |
| 사진 | 정확한 아종 매핑·개별 파일 조건 확인 | 아종 사진으로 대체하지 않음 |
| 보전 등급 | 현재 별도 자료 미검토·중립 표시 | 부모 등급을 상속하지 않음 |

참고 형질에는 reference_scope=species와 reference_taxon을 붙여 어떤 종의 자료인지 표시한다. 아종 직접 체중·먹이·서식지 데이터가 없다고 부모 값을 자동 복사하지 않는다.

### 분포 설명의 검토 범위

청둥오리의 conboschas·platyrhynchos 두 아종은 고정 분류판·taxon ID·학명·원문 분포문이 일치할 때 검토 요약을 표시한다. 그린란드 남서부 해안과 북반구의 넓은 번식·월동 범위라는 분포 차이를 설명하며, 깃털이나 형태로 구별할 수 있다는 근거를 추가하지 않는다. 다른 아종은 미검토 상태를 안내한다.

19,879개는 당시 TEST 그래프에 있던 아종 노드 수다. 모든 아종의 독립 형질·사진·한국어 설명을 갖췄다는 뜻이 아니다. 이번 작업은 기존 n8n 분류 자료 조회이며 새 수집기를 만든 결과가 아니다.
