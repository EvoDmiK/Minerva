### RG-504 — 확인된 한국어 이름 확대와 예전 분류명 매핑 검토

- [ ] 보류 — 최후순위
- **우선순위**: 최후순위 (2026-10-07 사용자 지시).
- **목적**: 확인 가능한 한국어 이름을 더 연결하고, 분할·통합·학명 변경으로 잘못 붙는 이름을 줄인다.
- **범위**:
  - 한국 도감·학회·공공기관 등 확인 가능한 자료에서 현재 수록 종·아종의 국명과 정확한 학명, 발행 시점, 출처 위치를 수집한다.
  - 종 국명과 아종 국명을 구분한다. 부모 종 국명을 아종 고유 국명으로 복사하거나 분포 설명을 공식 이름으로 승격하지 않는다.
  - 예전 학명은 현재 AviList 개념과 동일한지 검토한다. 이름이 바뀐 경우와 종이 분할·통합된 경우를 구별하고 일대다 매핑은 보류한다.
  - 기존 영어 아종 통칭의 충돌·미연결 후보도 같은 원칙으로 재검토한다. 가축형·품종 이름을 야생 아종에 붙이지 않는다.
  - 한국어 이름을 확인하지 못하면 출처 있는 영어 이름을 유지한다. 둘 다 없으면 RG-503의 설명용 제목을 사용한다.
- **완료 기준**:
  - 채택 이름마다 현재 ID·학명·출처·분류판 및 검토 근거가 남고 목록·카드·추가 정보에서 일관되게 표시된다.
  - 학명 변경, 종 분할/통합, 아종과 부모 종 이름 혼동, 가축형, 다중 후보와 미확인 이름의 회귀 검증을 통과한다.
  - 추가·수정·보류 건수와 한국어 이름 커버리지를 기록하고 여러 속의 NAS TEST 응답을 확인한다.
- **협업 권장**: Antigravity 자료 조사, Claude 이름·설명 검토, Codex 동일성 가드·연동·검증.
- **결과 기록 (2026-10-10 대조)**: 부분 진행·후속 보류. 활성 11,131종의 표시 경로와 기존 국명 원자료를 대조했고, 기관 근거 보강으로 검토 국명 665종을 확보한 뒤 남은 후보 408종 모두를 추가 조사했다. 독립 출처와 현재 분류 대응을 확인한 185종을 추가해 검토 국명은 총 850종이다. 223종은 독립 근거 미확보 130·출처 접근 또는 추가 근거 대기 75·다른 종 국명 충돌 16·비한글 후보 2로 남겼다. 조사 완료와 이름 확정 완료를 구분한다.
- **검증·남은 범위**: 실제 TEST DB 추출 전수 감사, 이름·계통 회귀, 대표 종 실제 TEST/PROD HTTP 검증은 총괄 기록을 따른다. 408종 전체를 각각 운영 채팅으로 검증한 것은 아니다. 출처 접근 실패를 국명 없음으로 확정하지 않으며, 미확정 이름과 예전 분류명·종/아종/가축형의 모든 완료 기준까지 충족한 것으로 처리하지 않는다.
- **상세 근거**: [[Work/RobinGraph/작업기록/5xx 데이터·분류·이름/2026-10-09-국명408-형질503-평가447-원자료복구|408종 조사·형질·보전 자료 총괄]]. 저장소 `docs/work-log/2026-10-09-korean-name-full-source-audit.md`, `docs/work-log/2026-10-09-remaining-species-resolution.md`, `docs/verification/assets/2026-10-09-korean-name-408-resolution.json`에 출처·결정·검증·한계를 보존했다.

### RG-505 — 분류·이름·번역 자료 변경 감지와 검토 가능한 갱신 절차

- [ ] 보류 — 최후순위
- **우선순위**: 최후순위 (2026-10-07 사용자 지시).
- **목적**: 새 원자료나 분류판이 나오면 오래된 이름·번역이 잘못 재사용되는 일을 막는다.
- **범위**:
  - 원자료 해시와 릴리스 변경, 학명·명명자·부모 관계·분포문·통칭의 추가/삭제/변경을 비교하는 보고서를 만든다.
  - 원문이 바뀐 한국어 요약은 재검토 대상으로 표시하고 다른 분류판에 참고 이름을 자동 이식하지 않는다.
  - 기존 수집·재생성·전수 감사 스크립트를 재사용한다. 반복 수집이 필요한 경우 n8n workflow로 실행·실패·출처 메타데이터를 기록한다.
  - 수집과 서비스 활성화를 분리한다. 변경 보고서를 검토하고 TEST 검증을 통과한 자료를 명시적으로 활성화하며 이전 버전으로 되돌릴 수 있게 한다.
- **완료 기준**:
  - 같은 원자료의 재실행은 변경 없음으로 끝나고, 해시 변경·출처 실패·이름 충돌·원문 변경은 각각 식별된다.
  - 실제 고정 입력의 재생성 결과가 바이트 단위로 일치하고 전체 감사 및 기존 실제 DB 테스트를 실행한다.
  - 변경 보고서·적용/보류 사유·롤백 절차·TEST 검증을 상세히 기록한다. PROD 활성화는 기존 RG-102 범위와 조율한다.
- **협업 권장**: Codex 수집·비교·감사, Antigravity 분류 변경 대조, Claude 검토 화면·설명.
- **결과 기록**: 미착수.

### RG-501 — 통칭과 가축화된 아종·가축형 조사 및 그래프 연결

- [x] 구현·확대 조사·NAS TEST 적재·실환경 검증 완료 (2026-10-03)
- **담당·모델**: codex / GPT-6.1 Sol 구현, antigravity / Gemini 3.1 Pro 조사, claude / Sonnet 4.6 검토.
- **목적**: 사람들이 자주 부르는 이름으로도 검색하고, 통칭과 분류상 종·아종·가축형의 차이를 설명한다.
- **조사 예시**: 비둘기 → 바위비둘기, 까마귀 → 큰부리까마귀, 닭 → 적색야계, 집오리 → 청둥오리. 이 화살표는 사용자 제시 조사 후보이며 확정된 동의어·분류 관계가 아니다.
- **범위**:
  - 이름의 지역·언어·사용 맥락, 후보 종, 가축화 및 분류 관계를 출처와 함께 조사한다.
  - 통칭·동의어·아종·가축형·기원 관계를 구분해서 그래프에 연결한다. 모든 가축형을 아종으로 단정하지 않는다.
  - 하나의 통칭이 여러 종을 뜻하면 후보 선택 또는 추가 질문을 제공한다. 대표 종을 임의로 확정하지 않는다.
