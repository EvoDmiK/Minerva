## 관리 기준

- 프로젝트 루트에는 이 인덱스·백로그·공통 가이드를 둔다.
- 기능을 구현하거나 수정·배포한 기록은 `작업기록/`에 저장하고 해당 폴더 인덱스에 추가한다.
- 별도 검토·감사·평가·설계 문서는 `검토자료/`에 저장하고 해당 폴더 인덱스에 추가한다. 검토자료에도 조사용 스크립트·산출물·실행 검증이 포함될 수 있으므로 폴더만 보고 구현 완료를 판단하지 않는다.
- 작업 중 검증·협업 검토·한계는 작업 문서에 함께 보존한다. 기존 상세 문서를 잘라 중복 문서로 만들지 않는다.
- 상태와 우선순위는 백로그, 실제 반영·배포 결과는 작업 원문을 기준으로 확인한다.
- 새 작업의 ID는 카테고리 번호(101, 201, …, 901)로 매긴다. 기존 RG-001~017은 번호를 바꾸지 않고 백로그의 대응표로 연결한다.
- 문서를 이동하면 연결 링크와 폴더 인덱스를 함께 갱신한다. 같은 이름의 `index.md`는 전체 Vault 경로로 연결한다.
