## 인덱스 정비 기록 — 2026-10-07

- **요청·목표**: Work의 각 프로젝트 폴더에 진입점이 되는 `index.md`를 두고 작업 문서를 쉽게 찾는다.
- **확인한 상태**: 4개 프로젝트 중 Birds-Nest·Gullinkambi에는 인덱스가 있었고 RobinGraph·Itzcuauhtli에는 없었다. 기존 인덱스에 일부 문서가 빠져 있었으며 Gullinkambi에는 Git 충돌 표시가 남아 있었다.
- **변경**: RobinGraph·Itzcuauhtli 인덱스 생성, Birds-Nest·Gullinkambi 전체 작업 기록 갱신, Work 상위 인덱스에 4개 프로젝트 링크 표 추가. 기존 프로젝트 설명·관련 링크·구성 요소를 보존하고 Gullinkambi의 충돌 양쪽 문서 링크를 모두 포함했다.
- **검증**: Work 목록을 기준으로 프로젝트별 비인덱스 문서가 모두 연결되는지, 링크 대상이 존재하는지와 충돌 표시 제거를 확인한다. 저장한 인덱스 5개를 다시 읽어 기대 내용과 일치하는지 검증한다.
- **적용 범위·후속**: Obsidian 인덱스 문서 5개만 변경한다. 기존 작업 원문·백로그 상태를 변경하지 않는다. 코드 변경이 없어 테스트·DB/API 검증·배포·Git 커밋은 수행하지 않는다. 이후 문서 추가·이동 시 프로젝트 인덱스와 상위 프로젝트 표를 함께 유지한다.
