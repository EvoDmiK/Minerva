# v4 데이터 · 층화 5-fold 재학습

**5개 fold 완료 — validation 정확도 평균 72.75%, Macro F1 평균 0.7224**

개선 데이터 800개와 도구 설명을 함께 적용했다. 기존 validation 결과로 선택한 최고 설정을 고정하고 회사 RTX 5070 Ti에서 재학습한다. test20 평균 정확도는 64%, Macro F1은 0.5887이다. test20은 반복 관찰한 합성 회귀 점검이다.

[MLflow 재학습 Parent](https://mlflow.dove-nest.com/#/experiments/47/runs/79480c4a3be84189906f4bc2924757fb) → [고정 설정](https://mlflow.dove-nest.com/#/experiments/47/runs/9fe16d70fb8c4a49b56125565912d615) → [첫 fold](https://mlflow.dove-nest.com/#/experiments/47/runs/ebb69afb5e2f4d6199c6f7f7cc685af7)

## 학습 구성

| 항목 | 설정 |
|---|---|
| 데이터 | hermes-ten-tools-v4, 800개, 도구당 80개 |
| 5-fold 분할 | fold당 학습 640개 / 검증 160개 |
| 도구별 분포 | 학습 64개 / 검증 16개 |
| LR / 배치 / seed | 0.00028884521694941566 / 4 / 3407 |
| 최대 epoch | 32 |
| 조기 종료 | 최소 8 epoch, patience 6, min_delta 0.004 |
| Scheduler / Warmup | cosine / 0 |
| Weight decay / Label smoothing | 0 / 0.1 |
| Gradient clipping | 2.0 |

각 fold는 고정된 원본 Laya 가중치에서 시작한다. 정답이 다른 대조 문장 쌍도 같은 scenario로 묶어 학습·검증 양쪽에 섞이지 않게 했다. 800개 모두 한 번씩 검증에 포함한다. 기존 validation20은 사용하지 않고 test20은 모델 선택에 사용하지 않는다.

## 저장과 검증

MLflow는 Parent → 고정 설정 → fold 1~5 구조다. 핵심 파라미터 10개와 에폭별 지표를 추적하며, 상세 설정·실제 fold 데이터·SHA-256·보고서는 JSON Artifact로 저장한다. Parent의 Dataset 입력은 저장된 v4 combined/train과 연결했다.

데이터 테스트 38개, CUDA 환경의 CV·계획 테스트 18개가 통과했다. 로컬·서버 fold 해시가 같고, 기존 train600의 분할 배정도 변하지 않았다. 코드와 설정은 dev-codex의 `6e009e6`으로 커밋·푸시했다.

- 계획: `configs/training/laya-ten-tools-v4-best-cv5-20261024.json`
- 모델 설정: `configs/training/laya-ten-tools-v4-best-cv5-20261024-model.json`
- 서버 상태: `outputs/laya-ten-tools-v4-best-cv5-20261024/tracking/state.json`
- [재현 명령과 상세 기록](https://github.com/EvoDmiK/Jery/blob/dev-codex/docs/data/laya-v4-retraining-20261024.md)

## 결과를 읽는 기준

이번 실행은 데이터와 설명을 함께 바꿔 재학습하므로 각각의 효과를 분리하지 않는다. 이전 600개 CV와 검증 모집단도 달라 점수 차이를 직접적인 개선 효과로 단정하지 않는다. 추가 데이터는 합성이며 사람 검토 대기 상태다.
