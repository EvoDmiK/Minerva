# Jery 10개 도구 단일 선택 학습 진단

사용자가 한국어 의도 분류는 별도 프로젝트에서 진행하고 Jery는 도구 10개로 실험하도록 요청했다.

## 과제와 데이터

Obsidian vault·edit·graph·dataview·bases 5개와 Swallow get_stock_price·get_price_history·get_portfolio·order·backtest 5개를 고정 후보로 사용한다. 요청과 호출 전 context, 한국어 기능 설명 10개를 한 창에 제공한다. no_tool·clarify·unsupported와 action 예측은 제외한다.

새 데이터셋 hermes-ten-tools-v1, catalog hermes-ten-tools-b4648cc19a90, 계약 decision-export-v2 / fixed_ten_tools_select_only다. 기존 96개 카탈로그와 원본 분할은 보존했다. 중복 입력을 제거하고 기존 시나리오 분할을 유지했다.

- 암기 진단: train 20개(도구별 2), validation 20개, test 20개.
- full profile: train 60개(도구별 6), validation 20개, test 20개.
- 두 profile의 validation/test는 바이트 단위로 동일하고 진단 train은 full train의 부분집합이다.
- 합성 정답은 미검토이며 실제 사용 성능을 의미하지 않는다.

## 협업과 검증

Claude가 CUDA 단일 10개 선택, train fit 기록과 도구별 macro F1을 구현했다(원 커밋 65ed4d3·88ffa7c, 통합 fb40469·666a8cb). AGY가 원본 해시, 재생성, 분할, 중복, 후보·정답, 입력 누수를 독립 감사했다(원 커밋 6703cf8, 통합 b927fef).

통합 후 전체 145개 테스트와 원본 v1/v2 검증이 통과했다. 실제 native builder/tokenizer readiness는 두 profile 모두 skip·target 불일치·학습/추론 특징 불일치·잘림 0건, 최대 229 token이었다.

## 실제 실행

회사 persona-ai Linux / RTX 5070 Ti에서 frozen FP16 encoder와 FP32 routing head를 BF16 autocast로 실행했다. 다른 회사 GPU 작업은 유지하고 Mac에서는 학습하지 않았다.

첫 [Parent 17ebcc82](https://mlflow.dove-nest.com/#/experiments/47/runs/17ebcc82ff7d43fc9d4d7d007cc4d29c) / Child 659bae0e7bbb480a9c0e72c431475cb7: LR 2e-5, 64에폭·320 optimizer step 완료. 학습 호출 59.31초, CLI 76.63초. head 31개 텐서가 바뀌고 encoder는 동일했다. 마지막 train 정확도는 70%, validation은 초기와 학습 head 모두 50%여서 serving은 초기 head를 유지했다.

학습 fit 95% gate를 통과하지 못해 full Hyperopt를 보류했다. Test 점수를 gate나 LR 조정 근거로 사용하지 않았다. LR 1e-3 재진단을 별도 [Parent 37611c82](https://mlflow.dove-nest.com/#/experiments/47/runs/37611c82fb924ba6bccb5d4410db9226) / Child c997b44b16b04a9c9f43c02725ef616e에서 실행했다. 첫 gate JSON은 두 Parent에 업로드하고 SHA-256 read-back을 확인했다.

MLflow Experiment는 Jery(47), Parent–Child 구조다. Child params 5개와 metrics 7개만 사용하며 나머지는 JSON artifact, 학습 head는 safetensors다. 이번 과제의 macro F1은 10개 도구 기준이며 기존 decision F1과 다르다.

## 진단 완료와 본 실험 시작

LR 1e-3 재진단은 64에폭·320 step을 완료했고 마지막 train 정확도 100%, 최고 trained validation은 epoch 18의 60%(초기 50%)였다. 학습 head 저장·재로딩 후 validation 예측과 확률이 동일했고 encoder는 유지됐다. Train fit gate를 통과한 JSON 증거를 진단 Parent에 업로드하고 해시 read-back을 확인했다. 마지막 train fit과 선택된 validation head는 서로 다른 평가 대상이다.

본 실험 Parent는 [c328674ecd9c4eabb1bf3d4dbc6c9dde](https://mlflow.dove-nest.com/#/experiments/47/runs/c328674ecd9c4eabb1bf3d4dbc6c9dde)다. 실제 train fit 결과에 따라 시작 전 LR 범위를 1e-4~1e-3, 최소 관찰을 32에폭으로 조정했다. 최대 64에폭·patience 5, Hyperopt TPE 5회이며 validation으로 비교하고 test로 튜닝하지 않는다. 코드·설정 5f1211b를 origin/dev-codex에 푸시하고 서버에 반영했다.
