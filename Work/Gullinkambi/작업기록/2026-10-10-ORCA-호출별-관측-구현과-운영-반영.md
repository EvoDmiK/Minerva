# ORCA 호출별 관측 구현과 운영 반영

명세 [[Work/Gullinkambi/2026-10-09-ORCA-Grafana-MLflow-Claude-작업명세|ORCA Grafana·MLflow·Claude 작업명세]]를 구현하고 NAS에 단계별로 반영했다.

## 결과
- 호출별 사용량(Codex/Claude) → collector → Cloudflare → n8n → TimescaleDB → Grafana 경로가 동작한다.
- 작업(manifest) 단위 MLflow Run이 자동 생성된다(세션별 `auto-<agent>-<session8>/a1`).
- 도구 호출 수 집계(Claude/Codex)가 Grafana 패널과 MLflow metric(`tool.<name>`)에 들어간다.
- kanban 텔레메트리 데이터 전체를 삭제했다.

## 구현·배포 내용
- **수집**: 호출 단위 fingerprint 상태, 배치 500건, 48h lookback. 알 수 없는 값은 0이 아니라 NULL + coverage로 표시(Unknown ≠ 0).
- **귀속**: 명시 manifest(`[start,end)` 또는 request hash)가 우선, `ambiguous`는 자동 묶지 않음, 자동 세션은 attribution_status `auto`.
- **스냅샷/exporter**: 스냅샷 revision + outbox + MLflow exporter(at-least-once, 태그 기반 reconcile). FINISHED는 "스냅샷 완료"이지 성공이 아님.
- **검증 분리**: 에이전트 보고와 verifier 증거를 분리. `orca_verify`는 HMAC 서명, 서명 없는 verifier 결과는 무시.
- **도구 집계**: 이름·횟수만 수집(프롬프트/경로/인자 미수집), MCP는 `mcp:<server>`로 축약.
- **DB**: `timescaledb/migrations/001~008`, 디스패처는 최신 마이그레이션과 동일하게 유지(테스트로 강제).
- **Grafana**: 요약 타일 상단 이동, 막대 이름 잘림 해결, 스레드 이름 대체 문구, 작업/시도 표 MLflow 열을 Run 이름으로 표시, n8n Data quality 행, 도구 호출 패널.
- **Antigravity/Codex 스레드명**: LaunchAgent 복구(Homebrew python 사용 — 시스템 python은 외장 SSD에서 TCC 거부).
- **MLflow 정리**: 에이전트/RobinGraph 접속을 내부 URL로 전환, 평문 DB 비밀번호 제거. 공개 라우트는 외부 조회 필요로 유지.

## 검증
- 단위·통합 테스트(호출 정규화, 귀속, 도구 집계, task/verify CLI, 파이프라인, exporter, collector) 통과.
- NAS에서 마이그레이션 적용 및 스모크 테스트 후 단계별 반영.
- Grafana 화면은 사용자가 라이브로 확인하며 피드백 반영(내가 직접 시각 검증한 것은 아님).

## 사고·한계
- 스모크 테스트 중 n8n Hermes Telemetry Ingest 500이 6건 발생(내 테스트, API 오류 패널에서 제외).
- RobinGraph 운영 API가 약 2분 40초 불가(환경 전환 시점에 Neo4j 재시작이 겹침). NAS SSH가 약 3분 끊김(원인 미상).
- Docker 단일 파일 bind mount는 atomic rename 시 inode가 끊겨 in-place 쓰기로 해결.
- Cloudflare가 기본 Python User-Agent를 1010으로 차단 → 커스텀 UA 사용.
- 서명 키는 같은 호스트의 공유 비밀이라 악의적 프로세스는 막지 못함.
- Codex 도구 실패 수는 신호가 없어 unknown.

## 남은 일
- MLflow 공개 라우트 보호(Cloudflare Access 등).
- DB 비밀번호 로테이션(git 이력, openclaw 상태 파일, 미추적 swallow-mcp 스크립트 잔존).
- NAS `.env` 권한(777) 정리.
- Antigravity 도구 호출 수집 미구현.
- n8n `[System] Birds Nest` 워크플로 409 충돌 원인 조사(24h 성공률 64%).
- RobinGraph `.env.nas.example` 기본 URL 정리.
