# Dove-Nest

김둘기의 지식 베이스 (Knowledge Base) 입니다.

Obsidian 스타일 마크다운 노트로 관리합니다. 폴더는 최소한으로만 나누고,
노트 사이는 `[[위키링크]]`와 태그(`#태그`)로 연결하는 것을 기본 원칙으로 합니다.

## 구조

```
Dove-Nest/
├── Home.md              # 전체 노트 모음(MOC, Map of Content) 진입점
├── Inbox/                # 빠르게 캡처한 미정리 메모
├── Dev/                  # 개발 / 프로그래밍 (코드 스니펫, 학습, 트러블슈팅)
├── Work/                 # 업무 / 프로젝트 (회의록, 진행 상황, 의사결정)
├── Learning/              # 개인 학습 / 독서 (책 요약, 강의 노트, 아이디어)
├── Templates/            # 새 노트 작성 템플릿
└── Attachments/          # 이미지 등 첨부파일
```

## 규칙

- 새 노트는 `Templates/note.md`를 기반으로 작성합니다.
- 노트 제목은 한국어/영어 무관하게 내용을 명확히 나타내는 이름으로 짓습니다.
- 관련 노트는 폴더 이동 대신 `[[노트 이름]]` 링크로 연결합니다.
- 각 영역(Dev/Work/Learning)의 `index.md`는 해당 영역의 MOC 역할을 합니다.
- 임시 메모는 `Inbox/`에 먼저 쌓고, 정리되면 알맞은 폴더로 옮깁니다.
