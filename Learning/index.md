## 학습노트와 작성 예정

[[Learning/학습노트/index|학습노트 인덱스]]에서 작성된 문서와 작성 예정 주제를 관리합니다. 현재 작성된 문서와 등록된 예정 주제는 없습니다.

## 관리 기준

- 기존 파일명은 유지하고 역할에 맞는 하위 폴더에 저장합니다. 원문 본문을 요약·해설로 덮어쓰지 않습니다.
- 문서 속성 `document_role`은 `source` / `verification` / `learning-note`로 구분합니다. 인덱스는 `index`입니다.
- 원문과 검증 문서는 `verification_note`·`source_note`로 서로 연결하고, 학습노트는 `source_notes`로 참조 자료를 연결합니다.
- 새 문서를 추가·이동할 때 분류별 인덱스와 이 목록을 함께 갱신합니다. 작성 예정 문서는 실제 내용이 생기기 전까지 예정 목록으로 관리합니다.

## 정리 기록 — 2026-10-07

- **요청·목표**: 원문·변환 검증·추후 작성 문서를 쉽게 구분합니다.
- **원인·변경 전후**: 루트에 섞여 있던 원문 2개와 검증 2개를 ‘원문’·‘변환검증’으로 이동하고, 향후 작성용 ‘학습노트’ 인덱스를 만들었습니다. 분류별 인덱스 3개와 이 전체 인덱스를 구성했습니다.
- **변경 범위**: 기존 파일명·원문 본문·검증 결과는 보존하며 경로 링크와 역할·문서 간 연결 메타데이터를 정리했습니다. 새 학습 내용이나 실험 결과는 생성하지 않습니다.
- **검증 방법**: 이동 전후 본문이 경로 치환 외에 동일한지, 문서 4개와 인덱스 4개의 저장 내용, 원문-검증 연결 및 링크 대상 존재 여부를 확인합니다. 이전 경로를 참조하는 다른 노트도 검색해 확인합니다.
- **배포·한계·후속**: Obsidian 문서 정리만 수행하므로 코드 테스트·DB/API 실험·배포·Git 커밋은 해당하지 않습니다. 원문 재수집이나 사실 검증은 수행하지 않습니다. 이후 문서 추가 시 각 인덱스를 함께 갱신합니다.
