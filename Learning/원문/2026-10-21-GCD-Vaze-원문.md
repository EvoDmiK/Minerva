## Abstract
In this paper, we consider a highly general image recognition setting wherein, given a labelled and unlabelled set of images, the task is to categorize all images in the unlabelled set. Here, the unlabelled images may come from labelled classes or from novel ones. Existing recognition methods are not able to deal with this setting, because they make several restrictive assumptions, such as the unlabelled instances only coming from known – or unknown – classes, and the number of unknown classes being known a-priori. We address the more unconstrained setting, naming it ‘Generalized Category Discovery’, and challenge all these assumptions. We first establish strong baselines by taking state-of-the-art algorithms from novel category discovery and adapting them for this task. Next, we propose the use of vision transformers with contrastive representation learning for this open-world setting. We then introduce a simple yet effective semi-supervised $k$-means method to cluster the unlabelled data into seen and unseen classes automatically, substantially outperforming the baselines. Finally, we also propose a new approach to estimate the number of classes in the unlabelled data. We thoroughly evaluate our approach on public datasets for generic object classification and on fine-grained datasets, leveraging the recent Semantic Shift Benchmark suite.

## 1. Introduction
Consider an infant sitting in a car and observing the world. Object instances will pass the car and, for some of these, the infant may have been told their category (‘that is a dog’, ‘that is a car’) and be able to recognize them. There will also be instances that the infant has not seen before (cats and bicycles) and, having seen a number of these instances, we might expect the infant’s visual recognition system to cluster these into new categories. This is the problem that we consider in this work: given an image dataset where only some images are labelled with their categories, assign a category label to each of the rest images, possibly using new categories not observed in the labelled set. We term this problem Generalized Category Discovery (GCD).

GCD naturally formalizes this human learning scenario. In machine learning, it has the potential to dramatically reduce the amount of supervision required to categorize large datasets. A common scenario for ML practitioners is to train a model on a labelled set, deploy it in the wild, and later find unlabelled images whose categories may or may not have been in the labelled set.

Existing formulations in the literature are ill-suited to this task. For instance, Semi-Supervised Learning (SSL) assumes that the unlabelled images only belong to the labelled classes. Meanwhile, Novel Category Discovery (NCD) assumes that the unlabelled images only belong to new classes. In contrast, in GCD, the unlabelled images can belong to either known or novel classes.

Our contributions are four-fold:
1. We formalize Generalized Category Discovery (GCD), a realistic and unconstrained image recognition setting.
2. We adapt SOTA algorithms from NCD to serve as strong baselines for GCD.
3. We demonstrate that contrastive learning with Vision Transformers (ViT) enables direct clustering in feature space without parametric classification heads prone to overfitting.
4. We introduce a semi-supervised $k$-means algorithm with constraints on labelled instances, coupled with a black-box method for estimating the unknown number of classes using Brent's algorithm.

## 2. Related Work
- **Novel Category Discovery (NCD):** Introduced by Hsu et al. and Han et al. Prior NCD methods (AutoNovel, RankStats, UNO) train parametric classifiers with cross-entropy and cluster-assignment heads, requiring that $D_U$ contains no instances from known classes.
- **Open-Set Recognition (OSR):** Focuses on rejecting novel instances as 'unknown', but does not attempt to cluster or discover the underlying novel categories.
- **Self-Supervised Learning & Vision Transformers:** Self-supervised methods (SimCLR, MoCo, DINO) learn strong visual features. In particular, DINO ViT learns feature spaces with emergent semantic segmentation properties and strong nearest-neighbor classification capabilities.

## 3. Generalized Category Discovery

### 3.1 Our Approach
Let $D = D_L \cup D_U$ where $D_L = \{(x_i, y_i)\}_{i=1}^N$ with $y_i \in Y_L$, and $D_U = \{x_i\}_{i=1}^M$ with latent ground truth labels $y_i \in Y_U$. $Y_L \subset Y_U$, and the set of novel classes is $Y_U \setminus Y_L$.

#### 3.1.1 Representation Learning
We adopt a ViT-B/16 backbone $f$ pretrained with DINO on ImageNet. Features are extracted from the [CLS] token and projected via an MLP head $\phi$ to $z_i = \phi(f(x_i))$.

1. **Self-Supervised Contrastive Loss ($L_u$):** For views $x_i, x_i'$ in batch $B$:
$$L_u(i) = -\log \frac{\exp(z_i \cdot z_i' / \tau)}{\sum_{n \in B, n \neq i} \exp(z_i \cdot z_n / \tau)}$$

2. **Supervised Contrastive Loss ($L_s$):** For labelled instances $i \in B_L$ with class-matching set $N(i)$:
$$L_s(i) = -\frac{1}{|N(i)|} \sum_{q \in N(i)} \log \frac{\exp(z_i \cdot z_q / \tau)}{\sum_{n \in B, n \neq i} \exp(z_i \cdot z_n / \tau)}$$

3. **Total Loss ($L_t$):**
$$L_t = (1 - \lambda) \sum_{i \in B} L_u(i) + \lambda \sum_{i \in B_L} L_s(i)$$
We fine-tune only the final transformer block with $\lambda = 0.35$ and $\tau = 0.07$.

#### 3.1.2 Label Assignment with Semi-Supervised $k$-Means
- Centroids for $Y_L$ are initialized as class means $\mu_c$ of $D_L$.
- Additional $|Y_U \setminus Y_L|$ centroids are initialized via $k$-means++ on $D_U$ constrained on existing centroids.
- In each iteration, labelled instances $D_L$ are constrained to stay in their true ground-truth cluster, while unlabelled instances $D_U$ are assigned to their nearest centroid in feature space.

### 3.2 Estimating the Class Number in Unlabelled Data
We define an objective function $f(k; D) = \text{ACC}(D_L)$ evaluating clustering accuracy on labelled instances after running $k$-means on $D$. When $k$ equals the true total number of classes $|Y_U|$, the labelled instances suffer minimal contamination. We optimize $f(k; D)$ over the range $[|Y_L|, 1000]$ using Brent's algorithm.

## 4. Experiments

### 4.1 Setup
- **Datasets:** CIFAR-10, CIFAR-100, ImageNet-100 (Generic); CUB-200, Stanford Cars, Herbarium19 (Fine-grained).
- **Metric:** Clustering Accuracy (ACC) with Hungarian assignment computed **once** across all classes $Y_U$, then evaluated on All, Old, and New subsets.
- **Training:** 200 epochs, SGD with cosine annealing, initial learning rate 0.1, batch size 128.

### 4.3 Estimating Number of Classes
- Ground truth vs Estimated: CIFAR-10 (10 vs 9, 10% err), CIFAR-100 (100 vs 100, 0% err), ImageNet-100 (100 vs 109, 9% err), CUB (200 vs 231, 16% err), Cars (196 vs 230, 15% err), Herbarium19 (683 vs 520, 28% err).

### 4.4 Ablation Study Highlights
- ViT backbone provides a +18.0%p gain over ResNet-50 on CIFAR-100.
- Supervised contrastive loss alone overfits to Old classes (New drops to 35.0%). Combining $L_u$ and $L_s$ restores New ACC to 56.6%.
- Semi-supervised $k$-means further boosts New ACC to 66.5% (+9.9%p).

---

## 5. Conclusion
GCD establishes a realistic, unconstrained paradigm for open-world category discovery. Directly clustering features from contrastively fine-tuned ViTs with constrained semi-supervised $k$-means outperforms parametric classifiers prone to overfitting on known categories.
