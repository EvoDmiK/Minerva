# Learning — 원문 보관본

외부 자료를 보관한 문서다. 원문 제목·작성자·게시일·출처 URL과 본문을 보존한다. 요약·번역·해설·개인 의견은 별도 학습노트에 작성한다.

‘원문’은 보관한 페이지의 원문을 뜻한다. 게시글이 소개한 논문 전체를 함께 보관했다는 뜻은 아니다.

## 관리

- 새 보관본은 이 폴더에 저장하고 `document_role: source`, 출처 URL, 수집일을 기록한다.
- `verification_note`에 변환 검증 문서를 연결하고 이 인덱스와 [[Learning/index|Learning 전체 목록]]에 반영한다.
- 내용을 정리하거나 번역한 새 글은 [[Learning/학습노트/index|학습노트]]로 구분한다.
