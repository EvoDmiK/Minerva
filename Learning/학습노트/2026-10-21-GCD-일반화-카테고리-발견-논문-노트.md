# Generalized Category Discovery (CVPR 2022) — 한국어 상세 분석

## 요약

기존 NCD(Novel Category Discovery)의 비현실적인 전제("미라벨 데이터는 전부 신규 클래스로만 구성된다")를 깨뜨리고, 라벨이 없는 데이터셋($D_U$)에 기존(Old/Seen) 클래스와 신규(New/Novel) 클래스가 임의의 비율로 뒤섞여 있는 현실적인 오픈월드 환경을 **Generalized Category Discovery (GCD)**로 공식 정의한 논문입니다. 사전학습된 Vision Transformer(ViT-B/16 DINO)의 [CLS] 토큰 표현을 지도·자기지도 대조 손실(Contrastive Loss)로 미세조정하고, 라벨 데이터를 앵커로 활용하는 **준지도 k-Means(Semi-supervised k-Means)**를 결합하여 파라메트릭 분류기의 라벨 과적합을 방지하면서 신규 카테고리를 고정밀도로 발견합니다.

## 내용

### 1. Introduction — 배경과 문제 정의

#### 1-1. 연구 동기와 기존 한계
- **선행 연구(NCD)의 비현실적 가정:**
  - 기존 NCD 문헌(Han et al., Hsu et al.)은 데이터 수집 과정에서 미라벨 샘플($D_U$)이 *오직* 신규 클래스($Y_U \setminus Y_L$)에서만 나온다고 가정함.
  - 하지만 유아의 시각 학습이나 실제 서비스 로깅 환경에서는 이미 알고 있는 객체(예: 개, 자동차)와 처음 보는 객체(예: 고양이, 자전거)가 아무런 구분 없이 동시에 섞여 들어옴.
- **Generalized Category Discovery (GCD)의 정의:**
  - 데이터셋 $D$는 라벨 세트 $D_L = \{(x_i, y_i)\}_{i=1}^N$ ($y_i \in Y_L$)과 미라벨 세트 $D_U = \{x_i\}_{i=1}^M$로 구성됨.
  - 미라벨 데이터의 실제 라벨 $y_i$는 기존 클래스($Y_L$)일 수도 있고, 새로운 클래스($Y_U \setminus Y_L$)일 수도 있음 ($Y_U$는 $D_U$에 존재하는 전체 클래스 집합이며 $Y_L \subset Y_U$).
  - 모델은 $D_U$의 모든 샘플에 대해 $Y_L$인지 $Y_U \setminus Y_L$인지 구분함과 동시에, 신규 클래스들을 의미론적으로 유의미한 독립 클러스터로 묶어내야 함.
- **핵심 도전 과제:**
  - 미라벨 데이터 내 클래스 총 개수 $K = |Y_U|$를 사전에 알지 못함.
  - 라벨이 있는 $D_L$에 대해 지도학습(Cross-Entropy)을 강하게 걸면 모델이 Seen 클래스 쪽으로 편향(Overfitting)되어 신규 클래스 형성을 억제함.

### 2. Methodology — 방법 상세

#### 2-1. 전체 파이프라인 개요
1. **백본 표현 추출:** ImageNet DINO로 자기지도 사전학습된 ViT-B/16을 백본 $f$로 채택하여 입력 이미지의 [CLS] 임베딩을 추출.
2. **대조 학습 파인튜닝 (Representation Fine-tuning):**
   - 선형 분류 헤드를 사용하지 않고, 비선형 MLP 투영 헤드 $\phi$를 거친 정규화 임베딩 공간에서 대조 학습을 수행.
   - 전체 데이터(라벨+미라벨)에는 자기지도 대조 손실($L_u$), 라벨 데이터에는 지도 대조 손실($L_s$)을 혼합 적용 ($L_t = (1-\lambda)L_u + \lambda L_s$).
   - 백본의 마지막 트랜스포머 블록만 파인튜닝하여 사전학습 일반화 성능을 보존.
3. **신규 클래스 개수 ($K$) 비지도 추정:**
   - 전체 데이터 $D$에 대해 다양한 $k$ 값으로 군집화를 수행한 후, 라벨 부분집합 $D_L$의 군집 정확도(ACC)를 목적함수로 삼아 Brent 알고리즘으로 최적의 $k$를 탐색.
4. **준지도 k-Means 군집화 (Semi-supervised k-Means):**
   - 추정된 $K$개 클러스터를 대상으로, $D_L$ 샘플은 자신의 원래 클래스 중심점에 강제 할당되도록 제약 조건을 부여하고 $D_U$ 샘플은 자유롭게 최적 클러스터에 배정.

#### 2-2. 단계별 상세 동작 메커니즘

##### (1) ViT 백본 및 DINO 사전학습 채택 이유
- 기존 NCD 연구는 주로 ResNet-18/50을 scratch부터 학습했으나, 실제 환경에서는 대규모 사전학습 가중치를 활용하는 것이 표준임.
- DINO 사전학습 ViT는 지도학습 백본 대비 k-NN 및 비지도 군집화 성능이 압도적으로 우수하며, 사람의 어노테이션 없이도 객체의 의미적 주요 부위(Semantic parts: 예: 새의 부리, 자동차 전조등)에 어텐션을 집중시키는 특성을 보유함.

##### (2) 표현 파인튜닝: 분류 헤드 배제
- 파라메트릭 선형 헤드를 붙여 Cross-Entropy를 적용하면 라벨이 존재하는 $Y_L$ 클래스 방향으로 특징 공간이 왜곡되어 미라벨 데이터의 Novel 클래스 발견이 붕괴됨.
- 따라서 파라메트릭 분류 헤드를 배제하고 임베딩 공간에서 직접 k-Means 군집화가 가능하도록 대조 손실만으로 특징 공간을 정렬함.

#### 2-3. 핵심 수식 및 손실 함수

미니배치 $B$ 내 각 이미지 $x_i$에 대해 두 가지 랜덤 데이터 증강 뷰(View) $x_i, x_i'$를 생성하고, MLP 투영 헤드를 거친 정규화 벡터 $z_i = \phi(f(x_i))$, $z_i' = \phi(f(x_i'))$를 계산함.

##### 1) 자기지도 대조 손실 (Self-Supervised Contrastive Loss, $L_u$)
라벨 유무와 무관하게 모든 인스턴스 $i \in B$에 대해 적용:
$$
L_u(i) = -\log \frac{\exp(z_i \cdot z_i' / \tau)}{\sum_{n \in B, n \neq i} \exp(z_i \cdot z_n / \tau)}
$$

##### 2) 지도 대조 손실 (Supervised Contrastive Loss, $L_s$)
라벨이 존재하는 인스턴스 $i \in B_L$에 대해, 동일한 라벨을 공유하는 배치 내 다른 샘플 집합 $N(i) = \{q \in B_L \setminus \{i\} : y_q = y_i\}$를 양성 쌍(Positive pair)으로 취급:
$$
L_s(i) = -\frac{1}{|N(i)|} \sum_{q \in N(i)} \log \frac{\exp(z_i \cdot z_q / \tau)}{\sum_{n \in B, n \neq i} \exp(z_i \cdot z_n / \tau)}
$$

##### 3) 총 목적함수 (Total Loss, $L_t$)
$$
L_t = (1 - \lambda) \sum_{i \in B} L_u(i) + \lambda \sum_{i \in B_L} L_s(i)
$$

**수식 기호 및 역할 정의:**
| 기호 | 의미 | 역할 및 동작 원리 |
| :--- | :--- | :--- |
| $z_i, z_i'$ | $x_i$의 두 가지 증강 뷰 임베딩 | 단위 구면(Unit sphere) 상에 투영된 L2 정규화 특징 벡터 |
| $\tau$ | Temperature 하이퍼파라미터 | 유사도 분포의 첨도 조절 (본 논문 기본값 $\tau = 0.07$) |
| $N(i)$ | $x_i$와 동일 클래스 라벨을 가진 샘플 인덱스 집합 | 라벨 데이터를 같은 의미 군집으로 밀착시키는 지도 인력 제공 |
| $\lambda$ | 손실 가중치 계수 | 본 논문 기본값 $\lambda = 0.35$. 라벨 데이터의 지도 신호가 전체 대조 공간을 압도하지 않도록 조절 |
| $B, B_L$ | 미니배치 전체 및 라벨 부분집합 | 전체 샘플의 인스턴스 분별과 라벨 샘플의 클래스 정렬을 동시 달성 |

#### 2-4. 준지도 k-Means (Semi-supervised k-Means)
- **중심점 초기화:**
  - 기지 클래스 $|Y_L|$개의 초기 중심점은 라벨 데이터 $D_L$의 클래스별 평균 벡터로 계산: $\mu_c = \frac{1}{|D_L^c|} \sum_{x \in D_L^c} f(x)$.
  - 신규 클래스 $|Y_U \setminus Y_L|$개의 초기 중심점은 미라벨 데이터 $D_U$에서 $k$-means++ 알고리즘을 수행하되 이미 확정된 $|Y_L|$개 중심점과의 거리를 반영하여 분산 초기화.
- **클러스터 할당 제약:**
  - $D_L$에 속한 샘플은 최적화 반복 과정 내내 자신의 실제 라벨에 해당하는 중심점에 고정 할당됨 ($z_i \in D_L^c \implies c^*(i) = c$).
  - $D_U$에 속한 샘플은 모든 $K$개 중심점 중 유클리드 거리가 가장 가까운 클러스터로 자유롭게 할당: $c^*(j) = \arg\min_k \|f(x_j) - \mu_k\|^2$.
  - 중심점 업데이트와 할당을 수렴할 때까지 교대 반복.

#### 2-5. 클래스 수($K$) 비지도 추정 알고리즘
- **핵심 가정:** 전체 데이터 $D$에 대해 $k$-means를 수행할 때, 설정한 클러스터 수 $k$가 실제 클래스 수 $|Y_U|$와 일치할 때 라벨 서브셋 $D_L$의 군집 정확도(ACC)가 최대화된다는 직관 ($f(k; D) = \text{ACC}(D_L)$).
- **Brent 알고리즘:** 탐색 구간을 $[|Y_L|, 1000]$으로 설정하고, 브렌트 최적화(Brent's method)를 적용하여 라벨 정확도 $f(k)$를 최대화하는 최적 $k$를 수렴 탐색 (연속 완화 후 최적화).

### 3. Experiments — 실험 및 결과 분석

#### 3-1. 평가 프로토콜 및 데이터셋
- **Semantic Shift Benchmark (SSB) 및 평가 데이터셋:**
  - **일반 객체 (Generic):** CIFAR-10 ($|Y_L|=5, |Y_U|=10$), CIFAR-100 ($|Y_L|=80, |Y_U|=100$), ImageNet-100 ($|Y_L|=50, |Y_U|=100$).
  - **세밀 분류 (Fine-grained):** CUB-200 ($|Y_L|=100, |Y_U|=200$), Stanford Cars ($|Y_L|=98, |Y_U|=196$), Herbarium19 ($|Y_L|=341, |Y_U|=683$).
  - 각 데이터셋에서 클래스의 50%를 $Y_L$로 지정하고, 해당 클래스 이미지의 50%를 $D_L$로 배정 (나머지 50% 이미지 + 나머지 50% 클래스 전량을 $D_U$로 구성).
- **평가 지표 (Clustering Accuracy, ACC):**
  $$
  \text{ACC} = \max_{p \in \mathcal{P}(Y_U)} \frac{1}{M} \sum_{i=1}^M \mathbb{I}(y_i = p(\hat{y}_i))
  $$
  - **Hungarian Matching 단일 실행 원칙:** 헝가리안 매칭은 전체 클래스 $Y_U$에 대해 **단 1회** 수행한 후, Old 서브셋과 New 서브셋의 정확도를 사후 분리 측정해야 함. (Old/New를 각각 따로 매칭하면 Old 클러스터가 New 평가에 전용되는 왜곡이 발생함).

#### 3-2. 실험 하이퍼파라미터 설정 표
| 항목 | 설정값 | 비고 |
| :--- | :--- | :--- |
| 백본 아키텍처 | ViT-B/16 (DINO 사전학습) | [CLS] 토큰 (768 차원) 사용 |
| 학습 에폭 및 옵티마이저 | 200 Epochs, SGD with Cosine Annealing | 초기 학습률 0.1 |
| 미니배치 크기 | 128 | GPU 메모리에 맞춤 |
| 파인튜닝 범위 | 최종 트랜스포머 블록 (Final block only) | 초기 11개 블록 동결로 DINO 지식 보존 |
| 손실 가중치 $\lambda$ | 0.35 | $L_t = 0.65 L_u + 0.35 L_s$ |
| Temperature $\tau$ | 0.07 | 표준 대조 학습 온도 |

#### 3-3. 정량 결과 (Quantitative Results)

##### 표 2: 세밀 객체 벤치마크 군집화 정확도 (ACC %)
| 방법 | CUB-200 (All / Old / New) | Stanford Cars (All / Old / New) | Herbarium19 (All / Old / New) |
| :--- | :--- | :--- | :--- |

  - 파라메트릭 분류기를 쓰는 UNO+는 Old 클래스에서 매우 높은 점수(예: CIFAR-100 Old 80.6%)를 내지만, New 클래스에서는 47.2%로 급락하여 극심한 편향을 보임.

#### 3-5. 정성 결과 및 어텐션 시각화 분석
- **어텐션 맵 전문화 (Semantic Part Specialization):**
  - DINO 사전학습 초기에는 어텐션 헤드들이 객체 전반에 분산되어 있었으나, 제안된 대조 학습 후 각 어텐션 헤드가 독립적인 물리 부위에 집중함.
  - Stanford Cars: 헤드 1은 '앞유리(Windshield)', 헤드 2는 '헤드라이트(Headlight)', 헤드 3은 '휠하우스(Wheelhouse)'로 국소화.
  - CUB-200: 헤드 1은 '부리(Beak)', 헤드 2는 '머리(Head)', 헤드 3은 '배(Belly)'에 집중.
  - 이러한 부위별 어텐션 분할 능력이 Old 클래스에서 New 클래스로 자연스럽게 전이(Transfer)되어 미지 객체의 식별력을 높임.

---

### 4. Discussion — 한계점 및 실무 적용 관점

#### 4-1. 저자가 밝힌 한계 및 구조적 약점
1. **비파라메트릭 추론 오버헤드 (Inference Overhead):**
   - 새로운 테스트 샘플이 유입되거나 서빙할 때 단일 순전파로 분류되지 않으며, 전체 임베딩 데이터셋에 대해 k-Means를 재실행하거나 최근접 중심점을 계산해야 함.
   - 데이터 규모가 커질수록 실시간 추론 지연과 메모리 점유율이 심각해짐.
2. **DINO 사전학습 백본 의존성:**
   - 백본 표현 품질에 전적으로 의존하므로, 자연 이미지와 도메인 갭이 큰 특수 산업 데이터(의료 영상, 특수 센서 데이터)나 텍스트 도메인에서는 DINO의 군집 분리 능력이 유지되지 않을 수 있음.
3. **클래스 불균형 (Class Imbalance) 취약성:**
   - k-Means 군집화 알고리즘은 본질적으로 균등한 크기의 구형(Spherical) 클러스터를 가정하므로, 롱테일(Long-tail) 분포 데이터셋에서는 소수 범주가 거대 범주에 흡수되는 클러스터 왜곡이 발생함.

#### 4-2. 후속 연구와의 연결: SimGCD (ICCV 2023)
- GCD의 비파라메트릭 한계를 극복하기 위해 제안된 후속 연구가 **SimGCD**임.
- SimGCD는 파라메트릭 분류 헤드를 다시 부활시키되, **엔트로피 정규화(Entropy Regularization)**를 통해 Seen 클래스 편향을 제거하고 단 한 번의 Forward Pass로 신규 카테고리를 초고속 분류할 수 있도록 개선함.
