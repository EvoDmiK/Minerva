# π0.5 논문 핵심 내용 — 한국어 정리

> 이 대화에서 앞서 제공한 한국어 요약·해설을 저장한 학습노트다. 논문 전문 번역본이나 PDF의 전체 Markdown 변환본이 아니다. 앞선 설명과 출처 링크를 보존했으며, 저장 과정에서 새 실험이나 추가 사실 검증을 수행하지 않았다.

**핵심은 “로봇이 처음 보는 집에서도 일을 하게 하려면, 자기 행동 데이터뿐 아니라 웹 지식·다른 로봇의 경험·언어 지시를 함께 학습해야 한다”는 거야.** 단순히 모델을 키운 논문보다는, **로봇의 일반화를 위한 학습 방법**을 제시한 논문으로 읽으면 좋아. ([pi.website](https://www.pi.website/blog/pi05))

## 1. 목표가 ‘새 물체’보다 어려운 ‘새로운 집’이야

π0.5는 학습 때 보지 못한 집에서 설거지 정리·침대 정돈 같은 작업을 수행하도록 평가했어. 물체 모양뿐 아니라 **배치·배경·작업 순서까지 달라지는 상황**을 다룬다는 점이 중요해. ([pi.website](https://www.pi.website/blog/pi05))

## 2. 서로 다른 데이터가 서로 다른 능력을 가르쳐

학습에는 다음을 섞어 사용해.
- **로봇 시연:** 실제로 어떻게 움직이는가
- **다른 로봇의 경험:** 다른 몸체·환경에서 배운 기술
- **웹 이미지·질의응답·물체 탐지:** 무엇을 보고 있는가
- **하위 작업 라벨·사람의 언어 코칭:** 다음에 무엇을 해야 하는가

대상 이동형 로봇 데이터는 약 **400시간**이지만, **전체 학습 데이터가 400시간이라는 뜻은 아니야.** 다른 출처의 데이터도 함께 사용해. ([pi.website](https://www.pi.website/blog/pi05))

## 3. ‘무엇을 할지’와 ‘어떻게 움직일지’를 연결해

예를 들면:

```text
“침실을 정리해”
    ↓
“베개를 집어”
    ↓
팔·그리퍼 등의 연속 동작 생성
```

특징은 별도의 범용 LLM 계획기와 로봇 정책을 단순히 연결한 게 아니라, **하나의 통합 모델이 상위 작업 판단과 하위 행동 생성을 담당한다는 것**이야. 동작 생성에는 전용 action expert를 사용해. ([pi.website](https://www.pi.website/blog/pi05))

## 4. 학습 효율과 실제 제어를 위한 표현을 구분해

- **사전학습:** FAST로 행동을 이산 토큰으로 표현해 다양한 데이터를 함께 학습
- **후속학습:** flow matching 기반 action expert를 추가해 연속 행동 생성

즉, **대규모 학습에 편한 방식과 실시간 제어에 적합한 방식을 조합**했어. ([pi.website](https://www.pi.website/download/pi05.pdf))

## 5. 가장 중요한 근거는 ‘데이터를 빼보는 실험’이야

- 다른 로봇 데이터를 빼면 작업 성능이 크게 떨어졌어.
- 웹 데이터는 모든 평가를 똑같이 개선하지는 않았지만, **낯선 물체 이해와 상위 작업 판단**에 도움이 됐어.
- 상위 작업을 실행 중 명시적으로 예측하지 않더라도, **그 예측을 학습에 포함하는 것 자체로 상당한 이득**이 있었어.

따라서 성과를 단순히 “계층적 계획을 넣었기 때문”으로만 설명하면 핵심을 놓쳐. **어떤 데이터를 함께 학습했는지**가 중요해. ([pi.website](https://www.pi.website/download/pi05.pdf))

## 다만 ‘범용 가사 로봇 완성’은 아니야

실제 집 평가는 **새로운 집 3곳**에서 수행했고, 주요 지표는 작업 단계의 완료 비율이야. 낯선 손잡이, 시야 가림, 서랍을 반복해서 여닫는 오류도 남아 있어. 긴 맥락과 기억 활용 역시 한계로 제시해. ([pi.website](https://www.pi.website/download/pi05.pdf))

**내가 이 논문에서 가져갈 교훈은:**  
**“행동을 잘 따라 하는 능력과, 상황을 이해하고 다음 일을 고르는 능력을 함께 가르쳐야 일반화가 좋아진다.”** 이 관점으로 보면 논문의 데이터 구성과 제거 실험이 가장 중요한 부분이야. ([pi.website](https://www.pi.website/blog/pi05))
