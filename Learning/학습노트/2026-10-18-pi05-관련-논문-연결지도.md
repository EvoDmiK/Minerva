# π0.5 관련 논문 연결지도

## 시작점

[[Learning/학습노트/2026-10-17-pi05-논문-핵심-내용-한국어-정리|π0.5 한국어 정리]]에서 출발해, 왜 연결했는지를 기준으로 읽는 지도다. 최초의 π0.5 설명은 그대로 두고 관련 연구를 보충했다. 각 논문 노트의 ‘근거’에 1차 자료와 확인 범위를 기록했다.

> 아래 분류와 읽기 순서는 편집상 비교 해석이다. 최신 논문의 전수 목록이나 동일 조건 성능 순위가 아니다. 논문 전문 번역본이 아니라 한국어 학습노트다.

## 1. 모델과 행동 표현 — ‘움직임을 어떤 방식으로 생성하나?’

- [[Learning/학습노트/2026-10-18-pi0-범용-로봇-정책-논문-노트|π0]] → π0.5의 직접 기반. VLM과 flow-matching action expert를 이해한다.
- [[Learning/학습노트/2026-10-18-FAST-행동-토큰화-논문-노트|FAST]] → π0.5 사전학습의 행동 토크나이저. DCT·양자화·BPE가 왜 필요한지 읽는다.
- [[Learning/학습노트/2026-10-18-OpenVLA-오픈-VLA-논문-노트|OpenVLA]] ↔ FAST → 차원별 행동 이산화와 구간 압축 토큰화의 비교다. 같은 토크나이저라는 뜻이 아니다.

## 2. 데이터와 일반화 — ‘어떤 경험이 무엇으로 전이되나?’

- [[Learning/학습노트/2026-10-18-RT-2-웹지식-로봇제어-논문-노트|RT-2]] ↔ π0.5 → 웹 시각언어 과제와 행동 학습의 결합을 비교한다.
- [[Learning/학습노트/2026-10-18-Octo-다중로봇-정책-논문-노트|Octo]] ↔ OpenVLA → 다중 로봇 데이터와 목표 환경 fine-tuning을 비교한다.
- VLM 초기화에 인터넷 지식이 포함되는 것과 로봇 학습 중 웹 과제를 co-training하는 것은 구별한다.

## 3. 계획과 실행 — ‘다음 일을 고르는 모델을 분리할까?’

- [[Learning/학습노트/2026-10-18-Hi-Robot-계층형-지시수행-논문-노트|Hi Robot]] → π0를 하위 실행기로 사용하는 실제 의존 관계다.
- Hi Robot ↔ π0.5 → 전자는 분리된 상위·하위 모델, 후자는 동일 모델의 고수준·저수준 추론이라는 비교다. 둘 다 계층적 추론을 다룬다.

## 추천 읽기 순서

1. **π0 → FAST → π0.5**: π0.5의 모델 구조와 학습 레시피 이해.
2. **RT-2 → OpenVLA → Octo**: 웹 지식, 로봇 데이터, 행동 표현, 적응 조건의 분리.
3. **Hi Robot → π0.5 재독**: 상위 판단과 하위 실행의 결합 방식 비교.

## 비교할 때 확인할 네 가지

- **새롭다는 뜻:** 물체·지시·배경·집·로봇 몸체 중 무엇이 새로웠는가?
- **추가 학습:** 목표 환경 시연이나 fine-tuning이 있었는가?
- **출력:** 이산 행동 토큰, diffusion chunk, flow-matching action expert 중 무엇인가?
- **측정값:** 전체 성공률, 하위 작업 진행도, 지시 정확도 중 무엇인가?

‘웹 지식 전이’가 새로운 운동 기술 획득을 보장하지 않고, ‘학습이 빠르다’가 ‘추론이 빠르다’와 같지 않다. ‘계층형’이라는 표현만으로 모델이 분리되어 있다고 단정하지 않는다.
