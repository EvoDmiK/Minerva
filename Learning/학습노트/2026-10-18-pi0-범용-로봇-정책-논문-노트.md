# π0 — 범용 로봇 정책의 연속 행동 생성

## 한 줄 요약

사전학습 VLM의 지각·언어 표현에 연속 행동 생성기를 결합하여, 여러 로봇의 조작 기술을 하나의 정책으로 학습한다. [1, §III–IV]

## 확인된 핵심

- PaliGemma 기반 VLM과 action expert를 결합한다. expert는 flow matching으로 연속 action chunk를 생성한다. [1, §III–IV]
- 다양한 로봇 데이터로 사전학습한 뒤, 정제된 고품질 데이터로 후학습하여 복잡한 작업에 특화한다. [1, §V–VI]
- 기본 정책의 직접 실행과, 후학습한 정책의 장기 조작 작업을 구분해서 평가한다. [1, §VI]

## π0.5와 연결되는 이유

π0.5가 직접 기반으로 삼은 모델이다. π0의 **VLM과 연속 행동 expert**를 먼저 이해하면, π0.5가 추가로 다루는 이종 공동학습·새 집 일반화를 구분하기 쉽다. [2, Abstract·§IV]

## 비교 해석과 한계

이 논문의 zero-shot은 사전학습 정책을 추가 후학습 없이 실행하는 설정이다. 사전학습에 포함된 작업 평가를 ‘모든 낯선 집에서의 무적응 성공’으로 읽으면 안 된다. VLM 초기화 자체가 인터넷 사전학습 지식을 포함하므로, ‘π0에는 웹 지식이 없다’는 대비도 부정확하다. [1, §III·VI]
