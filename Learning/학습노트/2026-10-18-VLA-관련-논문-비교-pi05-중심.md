# VLA 관련 논문 비교 — π0.5 중심

## 먼저 볼 결론

이 연구들은 ‘어느 모델이 가장 좋은가’라는 하나의 줄에 놓기보다, **웹 지식 전이, 여러 로봇 경험의 활용, 행동 표현, 상위 계획, 새로운 환경에서의 평가 조건**으로 나누어 읽어야 한다.

- **π0 → FAST → π0.5:** 연속 행동 생성 구조, 효율적인 행동 토큰화, 이종 공동학습의 결합을 이해하는 경로.
- **RT-2 ↔ OpenVLA ↔ Octo:** VLM의 의미 지식, 다중 로봇 데이터, 목표 환경 적응을 구분하는 비교.
- **Hi Robot ↔ π0.5:** 상위·하위 모델을 분리하는 방식과 동일 모델에서 두 단계 추론을 수행하는 방식의 비교.

> 아래 비교는 1차 논문을 읽고 종합한 학습용 해석이다. 동일 데이터·로봇·평가 조건으로 재현한 벤치마크가 아니므로 성능 순위를 뜻하지 않는다. **FAST는 완성된 VLA 정책이 아니라 토크나이저 부품**이다. 후속 코드나 변형의 기능을 원논문 모델에 소급하지 않는다.

## 1. 모델 구조와 행동 표현

| 연구 | 무엇을 제안했나 | 모델의 출발점 | 행동 표현·생성 | π0.5와의 관계 |
|---|---|---|---|---|
| RT-2 [1] | 웹 지식을 행동으로 전이하는 VLA | PaLI-X 또는 PaLM-E | 연속 행동 차원을 이산 구간으로 바꾸어 토큰 예측 | 웹 시각언어 과제와 로봇 행동 공동학습의 비교 대상 |
| OpenVLA [2] | 공개 VLA와 목표 로봇 설정 적응 | Llama 2와 DINOv2·SigLIP 시각 특징 | 차원별 이산 행동 토큰 | VLM 초기화·다중 로봇 데이터·적응 경로 비교 |
| Octo [3] | 유연한 입력·출력의 범용 로봇 정책 | transformer 정책과 T5 언어 조건 | 작은 diffusion head의 연속 action chunk | 다중 로봇 학습과 연속 제어를 비교하되 VLM 구조로 동일시하지 않음 |
| π0 [4] | 범용 로봇 제어를 위한 flow 모델 | PaliGemma VLM과 action expert | flow matching으로 연속 action chunk 생성 | π0.5가 직접 기반으로 삼은 모델 |
| FAST [5] | 행동 시퀀스 토큰화·압축 | 정책 외부의 토크나이저 | DCT → 계수 양자화 → BPE | π0.5 사전학습에서 사용하는 행동 표현 |
| Hi Robot [6] | 상호작용적 지시 수행을 위한 계층형 시스템 | 별도로 학습하는 상위 VLM과 하위 π0 | 상위 언어 명령을 하위 π0의 연속 행동으로 실행 | 고수준 판단과 저수준 실행의 결합 방식 비교 |
| π0.5 [7] | 이종 공동학습을 통한 새 환경 일반화 | π0 기반의 통합 모델 | 사전학습 FAST, 후속학습 flow-matching expert | 비교의 중심 모델 |

**읽는 법:** 토큰 기반과 연속 행동 기반을 단순한 성능 우열로 나누지 않는다. 행동 표현은 학습 효율·제어 주파수·추론 비용과 연결되지만, 데이터 구성과 모델 크기 등 다른 조건도 함께 달라진다.

## 2. 데이터와 상위 계획

| 연구 | 핵심 학습 재료 | 상위 판단·지시 처리에서 볼 점 |
|---|---|---|
| RT-2 [1] | 로봇 시연과 웹 시각언어 과제의 co-fine-tuning | 의미적 지시를 행동으로 연결하며, 일부 chain-of-thought 실험도 보고 |
| OpenVLA [2] | 사전학습 VLM 초기화와 Open X-Embodiment 로봇 시연 | 원논문 기본 모델의 직접 행동 출력·fine-tuning 경로가 중심 |
| Octo [3] | 여러 로봇의 시연, 언어 지시 또는 목표 이미지 | 새 입력·행동 공간으로의 적응이 중심이며 생성형 VLM 계획기와 동일 구조가 아님 |
| π0 [4] | 다양한 로봇의 조작 데이터, 정제된 후학습 데이터 | 기본 운동 정책과 복잡한 작업 특화를 먼저 구분 |
| FAST [5] | 행동 궤적에서 토크나이저를 학습 | 상위 계획 자체를 제공하지 않음 |
| Hi Robot [6] | 로봇 시연 및 합성된 복합 지시·피드백 예제 | 상위 VLM이 지시를 해석하고 원자적 언어 명령을 생성; 하위 정책과 분리 |
| π0.5 [7] | 다른 로봇, 다양한 환경, 웹 과제, 하위과제 라벨, 언어 코칭 | 동일 모델이 먼저 고수준 하위과제를 고르고 이를 조건으로 저수준 행동 추론 |

### 중요한 구별

1. **웹 사전학습 ≠ 웹 과제 공동학습:** VLM 초기화가 인터넷 지식을 포함한다고 해서 로봇 학습 단계에서도 웹 과제를 함께 넣었다는 뜻은 아니다.
2. **같은 모델 ≠ 한 번의 추론:** π0.5는 통합 모델을 쓰지만 고수준 하위과제와 저수준 행동을 두 단계로 추론한다.
3. **같은 계층형이라도 구성은 다름:** Hi Robot은 상위·하위 모델이 분리되어 있고, 실험의 하위 실행기는 π0다.
4. **학습 속도 ≠ 제어 지연:** FAST의 학습 효율과 실제 로봇의 실시간 추론 비용은 별도로 확인한다.

## 3. 일반화·평가 조건을 나란히 보기

| 연구 | 논문에서 확인할 평가 초점 | 잘못 확장하면 안 되는 주장 |
|---|---|---|
| RT-2 [1, §4–5] | 새로운 의미적 지시·시각 단서를 활용하는 조작 | 웹 지식만으로 로봇 시연에 없는 새로운 운동 기술까지 획득했다는 주장 |
| OpenVLA [2, §5–6] | 여러 로봇의 직접 제어와 목표 설정 fine-tuning | 목표 환경 적응 결과를 모든 낯선 환경의 무적응 일반화로 해석하는 것 |
| Octo [3, §IV–V] | 다중 로봇 정책과 새 센서·행동 공간 적응 | fine-tuning이 포함된 결과를 새 모바일 가정의 zero-shot 결과로 바꾸는 것 |
| π0 [4, §VI] | 사전학습 정책의 직접 평가 및 후학습한 장기 조작 | 후학습 없는 평가를 곧바로 학습에 없던 모든 작업·주택 평가로 보는 것 |
| FAST [5, §VI–VII] | 행동 압축과 이를 이용한 정책 학습 | 토크나이저 자체가 계획·제어·새 집 일반화를 보장한다는 주장 |
| Hi Robot [6, §5] | 복합 지시·실시간 수정·제약에 대한 상호작용 수행 | 지시 정확도·작업 진행도를 전체 작업 성공률과 같은 값으로 읽는 것 |
| π0.5 [7, §V] | 학습에 포함되지 않은 집과 이종 공동학습 재료의 효과 | 평가된 범위를 넘어 임의의 집·물체·장기 작업에서 항상 성공한다고 보는 것 |

같은 ‘일반화’라도 **물체, 시각 배경, 지시, 장소, 로봇 몸체, 센서·행동 인터페이스**는 서로 다른 축이다. 성능표를 비교할 때는 목표 도메인 시연·추가 학습 여부와 지표 정의를 먼저 맞춘다.

## 4. π0.5를 이해하기 위한 핵심 질문

- **왜 π0가 필요한가?** VLM과 연속 행동 expert의 출발 구조를 이해하기 위해.
- **왜 FAST가 필요한가?** 사전학습의 행동 토큰과 후속 연속 행동 생성이 왜 병존하는지 이해하기 위해.
- **RT-2와 무엇을 비교하나?** 의미 지식과 로봇 경험을 함께 학습하는 방식.
- **OpenVLA·Octo와 무엇을 비교하나?** 여러 로봇 데이터, 모델 구조, 목표 환경에서의 추가 적응 조건.
- **Hi Robot과 무엇을 비교하나?** 계획·지시 해석 계층을 별도 모델로 둘지, 통합 모델에서 처리할지.

이 질문들은 읽기 위한 해석 틀이며, 특정 모델의 우월성이나 실제 배포 적합성을 검증한 결론은 아니다.
