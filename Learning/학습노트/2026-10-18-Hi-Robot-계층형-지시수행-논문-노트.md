# Hi Robot — 상위 언어 판단과 하위 행동 실행

## 한 줄 요약

복잡한 사용자 지시와 실행 중 피드백을, 상위 VLM이 원자적 언어 명령으로 바꾸고 하위 VLA가 실행하는 계층형 시스템이다. [1, §4]

## 확인된 핵심

- 상위·하위 정책은 같은 PaliGemma 계열에서 출발하지만, 서로 다른 감독으로 각각 학습한다. 실험의 하위 정책은 π0다. [1, §4.4]
- 시연을 짧은 skill로 분절·라벨링하고, 이를 바탕으로 생성한 가상 사용자 지시·끼어들기·로봇 응답을 상위 정책 학습에 사용한다. [1, §4.3]
- 테이블 정리·샌드위치 만들기·식료품 쇼핑에서 복합 지시와 실시간 수정에 대한 수행을 평가한다. [1, §5]

## π0.5와 연결되는 이유

둘 다 고수준 언어와 저수준 행동을 연결한다. 다만 Hi Robot은 **분리된 상위·하위 모델**, π0.5는 **동일 모델의 두 단계 추론**이라는 차이가 있다. ‘Hi Robot만 계층형’이라고 구분하면 안 된다. [1, §4.4; 2, §II]

## 비교 해석과 한계

주된 비교 축은 상호작용적 지시 이해와 계획 구조다. π0.5와 평가 조건이 같지 않으므로 성능 순위를 만들지 않는다. 작업 진행도와 전체 작업 성공률 역시 구별해야 한다. 실험 재현은 수행하지 않았다.
