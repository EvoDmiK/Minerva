# RobinGraph 조류 도감 카드 개선과 NAS 배포

> 자동 증류 초안 · 원천 [[Work/RobinGraph/작업기록/4xx 채팅 UI·카드/2026-10-01-조류도감카드-대화버그수정-멸종위기등급-NAS배포]] · 분류 근거 {"인프라":0,"자동화":3,"관측성":0,"데이터":3}

## 1. 개요 및 목적

조류 종 정보를 수집형 카드 스타일의 팝업으로 제공하고, 앞면에는 간단한 정보, 뒷면에는 출처를 담았다. 한국어 특성 표시, 사진 이동 버튼, 출처 토글을 추가했으며, 대화를 지우지 않고 다음 질문을 보내면 동작하지 않던 버그를 수정했다.

서식 환경별 문양과 멸종 위험 등급별 카드 색상·광택을 적용했다. 채팅 답변은 출처가 있는 짧은 한국어 설명과 카드 표시 버튼을 함께 제공한다. 최종 코드를 NAS TEST와 PROD에 배포하고 양쪽 상태와 정적 파일을 확인했다. 실제 종 데이터 검증은 TEST에서 수행했다.

## 4. 검증 근거 및 트러블슈팅

서식 환경별 문양과 멸종 위험 등급별 카드 색상·광택을 적용했다. 채팅 답변은 출처가 있는 짧은 한국어 설명과 카드 표시 버튼을 함께 제공한다. 최종 코드를 NAS TEST와 PROD에 배포하고 양쪽 상태와 정적 파일을 확인했다. 실제 종 데이터 검증은 TEST에서 수행했다.

> [!info] 배포와 검증 범위
> TEST에는 종 데이터가 있어 기능을 실제 데이터로 검증했다. PROD에도 같은 코드를 배포했지만 활성 종 데이터가 없어, PROD에서는 서비스 상태와 배포 파일 일치 여부를 확인했다.

| 요청 | 반영 결과 |
| --- | --- |
| 참고 이미지처럼 카드 팝업 표시 | 은색 테두리, 둥근 모서리, 질감이 있는 카드 팝업 |
| 앞면은 간단하게, 뒷면은 출처 중심 | 앞면 최대 4개 핵심 특성, 뒷면 전체 특성과 자료 출처 |
| 연속 질문이 동작하지 않는 문제 수정 | 대화를 지우지 않아도 버튼·Enter로 다음 질문 가능 |
| 영어 특성 값을 한국어로 표시 | 먹이 유형·서식 환경·주 생활 방식의 원본 어휘를 한국어로 매핑 |
| 출처를 펼치고 접기 | 특성·사진·등급 출처를 기본 접힌 토글로 표시 |
| 버튼으로 사진 이동 | 이전·다음 버튼, 사진 번호, 처음·마지막 버튼 비활성화 |
| 서식 환경마다 문양 구분 | 11개 환경별 SVG 문양과 한국어 접근성 이름 |
| 높은 위협 등급일수록 희귀 카드 같은 표현 | 등급별 색상·광택 차등 적용, 정보 부족·미평가는 중립색 |
| 설명과 카드 버튼을 함께 표시 | 자료에 근거한 짧은 설명 → 환경·등급 표시 → 카드 버튼 |
| Claude와 두 GPT 모델 협업 | Claude 디자인, GPT-6.1-Sol 백엔드, GPT-6-Sol 독립 검토 |
| 테스트 및 NAS 배포 | 자동 테스트 139개 통과, 브라우저 검증, TEST·PROD 배포 |

앞면에는 종의 한국어 이름과 학명, 서식 환경 문양, 적색목록 등급, 사진, 핵심 특성을 표시한다. 핵심 특성은 체중·먹이 유형·서식 환경·주 생활 방식 중 확인된 값으로 구성한다.

확인되지 않은 환경에는 중립 문양과 `서식 환경 미확인` 표시를 사용한다. 문양에는 한국어 접근성 이름을 부여했다.
