## 4. 검증 근거 및 트러블슈팅

> **문서 상태: 진행 중 (UI 구현 진행 중, TEST 배포 및 실서버 검증 대기)**  
> 사용자 승인에 따라 RG-203 그래프 관계 기반 질의응답 기능의 시각적 완성도와 사용성을 높이기 위한 후속 UI 디자인 정리 작업에 착수했다. root가 JS 결과 목록 접기/펼치기 UX를 구현하고, Antigravity가 CSS 스타일시트 디자인을 전담한다. 현재는 코드 작성 및 문서 준비 단계이며, TEST 배포 및 실제 실서버/브라우저 검증 결과는 전달되는 시점에 추가 반영한다. 운영 배포 및 Git commit/push는 수행하지 않는다.

- **배경 및 목적**:
  - RG-203 관계 질의응답(공통 분류, 동일 속, 서식지 겹침, 먹이 공유 등)은 최대 20종의 종 목록(`limit=20`, `has_more: true`), 분류학적 계층 경로(LCA), 출처 배지, 자료 부족 안내 등 다양한 구조화 정보를 출력한다.
  - 많은 종이 반환될 때 채팅 말풍선이 지나치게 길어져 모바일 및 데스크톱 환경에서 스크롤 피로도가 높아지는 문제를 해결하고, 계층 경로 및 출처 링크의 가독성을 제고하기 위해 후속 UI 디자인 정리를 진행한다.
- **역할 분담 및 협업 구조**:
  - **root**: `src/robingraph/api/static/chat.js`의 결과 종 목록 기본 개수 제한 및 접기/펼치기(더보기) 토글 상호작용 구현.
  - **Antigravity**: `src/robingraph/api/static/chat.css`의 카드 레이아웃, 버튼/태그 스타일링, 여백 및 반응형(데스크톱 1280px / 모바일 390px) CSS 작성.
  - **Writer**: 작업 진행 현황 및 추후 전달될 검증 증거의 무손실 기록·백로그 동기화.
  - **Codex**: 통합 검토, 회귀 테스트 및 TEST 배포 관리.
- **현재 상태 및 진행 기준**:
  - 현재는 프런트엔드 JS/CSS 작성 단계이며, **아직 TEST 환경 배포 전**임.
  - 자동화 테스트 및 실제 브라우저/API 실측 검증 결과는 증거 자산 전달 시 기록 예정.
  - 예정 증거 자산 디렉터리: `dev-codex/docs/verification/assets/2026-10-22-graph-query-design/`.
  - 운영 배포, 운영 DB 조작, Git commit/push 일체 없음 (`production_changed: false`, `git_commit_push: false`).

1. **JavaScript 목록 접기/펼치기 구조 (`chat.js`)**:
   - `ChatGraphResult` 응답 렌더링 시 반환된 종 목록 개수를 확인.
   - 일정 개수 초과 시 기본 항목만 먼저 표시하고, 하단에 잔여 개수를 안내하는 접기/더보기 토글 버튼(`[더보기 N개 더]`, `[접기]`) 배치.
   - 각 종 버튼 클릭 시 기존의 `profile` 패널 조회 연동은 그대로 유지.
2. **CSS 전용 스타일시트 고도화 (`chat.css`)**:
   - `.graph-query-answer` 컨테이너 내부의 구조화된 클래스 부여:
     - `.graph-query-path`: 분류학적 계층 경로 칩/배지 스타일
     - `.graph-query-species-list`: 종 목록 래퍼 (그리드/플렉스 정렬)
     - `.graph-query-toggle-btn`: 접기/펼치기 토글 버튼 스타일
     - `.graph-query-limitation`: 자료 부족 및 한계 안내 박스 스타일
   - `reducedMotion: 'reduce'` 미디어 쿼리 준수 및 터치 영역(최소 44px) 고려.
