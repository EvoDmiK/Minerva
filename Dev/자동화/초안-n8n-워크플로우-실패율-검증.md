Grafana MCP에서 n8n 대시보드와 PostgreSQL 데이터소스를 발견했다. 현재 MCP에 SQL 실행 도구가 없어 동일 Grafana의 조회 API로 SELECT 집계를 수행했다. 실패율은 `error`·`failed` 건수를 `success`·`error`·`failed` 완료 기록 수로 나눈 비율이며, 수동 실행도 포함했다.

시작 시각이 없는 실패 기록이 발견돼 최근 기간 집계는 종료 시각 기준으로 교정했다. 세 기간 각각 35개 워크플로우의 포함 여부, 비율 재계산, 전체 합계를 확인했다. 자세한 수치와 원문은 아래에 보존한다.
