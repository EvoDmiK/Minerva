# Dev — 개발 / 프로그래밍

개발 및 홈랩 인프라 운영에서 재사용 가능한 **핵심 엔지니어링 지식·아키텍처 패턴·스니펫·트러블슈팅 기준**을 모아둔 상록수 노트(Evergreen Notes) 인덱스(MOC)입니다.

프로젝트별 시계열 작업 일지는 [[Work/index|Work]] 영역에 기록하며, 그중 범용적 가치가 높은 기술 패턴을 이 영역으로 승격하여 **카테고리별 하위 폴더와 ID 체계(`DEV-1xx`~`DEV-4xx`)**로 관리합니다.

## 관리 기준

- **카테고리 폴더 분리**: 모든 Dev 문서는 도메인별 하위 폴더(`인프라/`, `자동화/`, `관측성/`, `데이터/`)에 위치합니다.
- **작업 ID 연동**: `DEV-1xx`부터 부여되며, 상위 백로그 및 프로젝트 작업 기록과 상호 링크(`[[...]]`)됩니다.
- **증류 자동화**: `scripts/distill_knowledge.py`를 통해 신규 `Work/` 기록에서 도메인별 하위 폴더로 초안을 자동 생성할 수 있습니다.
