# [RG-212 후속] 고정된 TEST 앱의 신규 36문항·12질문군 평가 — 2026-10-26

> 자동 증류 초안 · 원천 [[Work/RobinGraph/작업기록/2xx 검색·RAG·그래프 질의/2026-10-26-RG212-신규36문항-질문군-최초평가]] · 분류 근거 {"인프라":0,"자동화":0,"관측성":4,"데이터":2}

## 1. 개요 및 목적

사용자의 “계속 테스트” 요청에 따라 10월 24일 TEST 앱을 변경하지 않고 개발에 사용하지 않은 새 질문군으로 평가했다. 신규 36문항 중 23개가 판정 기준을 통과하고 13개가 실패했으며, 질문군은 12개 중 4개 통과·8개 실패였다. 실제 종 답변은 11건으로, 23개 판정 통과 전체를 답변 성공으로 해석하지 않는다.

이전 24문항·8개 군의 최종 통과는 실패를 보고 수정한 피드백 노출 회귀였다. 이번 최초 실측과 합치지 않았고, API 결과를 본 뒤 앱·gold·평가 알고리즘을 수정하거나 재호출해 통과로 바꾸지 않았다. 결과와 원본 응답을 MLflow에 저장하고 재조회했다. RG-212는 진행 중이며 앱 수정·새 배포·운영 반영은 하지 않았다.

이번에는 기존 앱을 고정한 상태에서 동치 문항의 조건 보존과 대조 문항의 차이를 함께 검사했다. HTTP 200이나 trace 처리 성공만으로 의미 해석·실제 실행의 성공을 판단하지 않았다. 같은 요청의 실행 계획, 조건, 응답 분류를 함께 확인했다.
