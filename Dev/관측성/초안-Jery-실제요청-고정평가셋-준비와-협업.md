## 1. 개요 및 목적

실제 요청 약 100개(고정 10개 도구별 10개)로 이전 선정 head와 보강 head를 비교하려고 수집·평가·감사 코드를 준비했다. 현재 자료가 부족하여 평가셋 동결, 모델 평가와 추가 학습은 실행하지 않았다.

Codex는 읽기 전용 출처 조사·정제·공통 계약·통합, Claude는 동결 평가 게이트와 고정 head 평가 CLI·독립 검토, Antigravity는 중복·출처·개인정보 감사와 독립 라벨 제안을 맡았다. 실제 Orca Claude·Antigravity 작업자를 사용했으며 Run은 run_dcd112b846ce다. 세 작업의 구현과 검토는 완료했지만 데이터 확보 목표는 미완료다.

## 4. 검증 근거 및 트러블슈팅

접근 가능한 Hermes 프로필의 root Discord user 기록은 2,050개, 활성·미압축 기록은 469개였다. 비활성·압축 1,581, 길이 제한 55, 도구 연관어 없음 381, 시스템 주입 알림 19, 개인 서술 격리 1을 제외해 최종 후보 13개(10개 세션 그룹)가 남았다. 열린 세션의 메시지는 context=[]인 독립 문장 후보로만 취급했다. tool call·결과·이후 답변은 입력·정답으로 사용하지 않았다. 사용자에게서 추가 과거 로그 출처가 없음을 확인했다.

전체 테스트 168개 통과. 기존 데이터 검증은 130 examples / 10 tools / 65 isolated scenarios PASS. 과거 자료 1,484개(진단 포함)에 대한 정확·정규화·근접 중복 0개, 정제·입력 경계 검사 위반 0개였다. 검사 범위의 결과이며 개인정보 완전 제거 보증은 아니다.

실제 candidate 패킷에서 human 게이트는 미해결 13개, provisional-ai 게이트는 미해결 12개를 거부했다. 승인된 동결 manifest가 없는 채점도 모델 로드 전에 거부했다. 실제 GPU head 비교는 아직 실행·검증하지 않았다.

원문·가명 키·실제 후보·AI 제안은 Git 제외 private 로컬 파일로 유지했다. 코드·합성 테스트·집계 보고서만 커밋했다. 독립 제안 원본을 보존하며 숫자 confidence의 문자열 표현과 action 없는 도구의 null action 생략만 통합 계약에 맞췄다.

앞으로 실제 사용 요청을 누적하고 정답을 검토해 도구별 부족분을 채워야 한다. 사용자가 직접 작성한 테스트 요청을 추가하면 authored 출처로 구분하고 실제 관측 로그 기반 평가와 별도로 보고한다. 실제 평가가 가능해지면 같은 입력·명세·정답으로 한 Parent 아래 두 Child에서 비교한다.
