## 4. 검증 근거 및 트러블슈팅

회사 RTX 5070 Ti에서 다른 시뮬레이션이 실행 중이다. 기존 작업을 유지하고, GPU가 30초 간격으로 두 번 연속 유휴 상태로 확인되면 실험이 자동 시작되도록 대기 프로세스를 실행했다. 이 확인은 GPU 예약은 아니다.

동일한 800개 검증 사례를 scenario 그룹이 겹치지 않도록 5-fold로 고정한다. 각 조건에서 동일한 요청·정답·후보 순서를 평가하고, 설명 변경 조건에는 해당 버전의 도구 설명을 적용한다.

| 조건 | 학습 사례 / fold | 설명 |
|---|---:|---|
| baseline | 기존 600개 중 검증 제외, 478~481개 | 기존 |
| data_only | 640개 | 기존 |
| description_only | 기존 600개 중 검증 제외, 478~481개 | 개선 |
| combined | 640개 | 개선 |

각 fold의 검증 사례는 160개다. 추가한 대조 쌍은 같은 scenario에 묶인다. 네 조건 × 5 fold 총 20회이며, 이전 최고 설정과 seed 3407을 고정한다. 모델 선택은 validation 정확도 기준이고, 반복 관찰한 test20은 보조 회귀 점검으로만 사용한다.

기존 데이터 검증 130개, 로컬 데이터 테스트 40개, CUDA 서버 CV 테스트 10개와 ablation 테스트 2개 통과. 네 fold 묶음의 해시가 로컬과 서버에서 일치했다. 커밋 `84cf354`을 dev-codex에 푸시했다.
