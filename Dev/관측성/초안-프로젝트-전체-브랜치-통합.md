## 4. 검증 근거 및 트러블슈팅

통합 과정에서 NAS 신규 NPM(Nginx Proxy Manager) exporter compose 및 Prometheus 설정 추가, `dev` 브랜치의 Kestrel / TelemetryIngest / carrier_pigeon 워크플로우 갱신을 흡수했다. 상충되는 변경에 대해서는 telemetry 최신 project label 회귀 테스트와 Magpie → Owlie 리네임을 보존하고, Swallow의 AI 검증·MLflow·뉴스 영향도·백테스트·가격표시·SQL 도구를 삭제/축소하려던 `dev-mac`의 구버전 변경을 배제하여 최신 `dev-codex`의 기능(22노드, 39 계약 테스트, 매크로 3대 지표 수집 및 쉼표 포맷)을 온전히 유지했다.

통합 후 Swallow 39 pass, Telemetry 131 pass(48 skip, 0 fail), NPM fixture 통과, 실제 NAS Grafana SQL 21 pass 및 graphify update를 검증 완료했다. 신규 n8n 및 모니터링 컴포넌트의 실서버 배포와 전체 E2E 검증은 미실행 상태이며, 기존 Draft PR #5 업데이트를 통해 사용자가 최종 main 머지를 진행할 예정이다.
