# [RG-212 후속] 검증된 유사 질문 활용·현재 조건 검증·구체적 되묻기 — 2026-10-24

## 1. 개요 및 목적

사용자는 검증된 유사 질문의 예시를 검색하고 현재 질문의 조건을 추출·검증한 다음, 모호한 부분을 구체적으로 되물어 그래프 조회로 이어지는 흐름을 요청했다. 기존 router와 semantic 구현에 계약 검증을 통과하는 예시 풀, 원문 근거를 짚는 되묻기, 질문군 단위 평가를 통합했다. 첫 실제 TEST 평가에서 tuning 6/6·2/2군, 봉인 holdout 16/18·4/6군을 확인했다. 봉인 문항 두 건의 false hold를 발견해 요청 말끝과 제외 표현 구두점 처리를 보완했으며, 최종 피드백 노출 회귀는 24/24·8/8군을 통과했다. 실제 답변은 19건이며 나머지 5건은 자료 부족·검색 결과 없음·지원 불가·부정 보류로 구분했다. TEST에 반영했고 운영에는 반영하지 않았다.

RG-206의 유형 후보 검색과 RG-207의 원문 조건 검증은 이미 검증 범위를 정해 완료된 선행 기능이다. 이번 작업은 이들을 새 기능 전체로 다시 완료 처리하지 않고 RG-212의 후속 작업으로 연결한다. 유사 질문의 조건이나 과거 답변을 현재 요청의 조건·실시간 답변으로 대체하지 않는 점을 기록한다.

기존 검색·해석·검증·조회 사이의 경계를 유지하고, 질문을 확인해야 할 때 원문 조건을 짚도록 변경했다. 새 대화 저장 계층이나 새 자동 학습 파이프라인을 만드는 대신 기존 계약을 재사용했다.
