# RG-401~RG-404·RG-502 비교·생태 정보·사진 개선

> 자동 증류 초안 · 원천 [[Work/RobinGraph/작업기록/4xx 채팅 UI·카드/2026-10-03-RG005-RG009-비교-생태정보-사진처리-NAS배포]] · 분류 근거 {"인프라":0,"자동화":0,"관측성":0,"데이터":2}

## 1. 개요 및 목적

RG-401~RG-404·RG-502는 각각 독립된 작업이다. RG-201 아래의 번호 순서 배치를 하위 작업 구조로 잘못 해석하여 요청 범위를 혼동했다. 이번에 구현·배포·검증한 결과는 RG-401~RG-404·RG-502에 해당하며, 이를 RG-201 완료로 보고했던 설명을 정정한다. RG-201은 원래 관계 탐색 확장 범위와 완료 기준을 별도로 확인해야 한다. RG-501의 통칭·가축형 관계 확대 작업은 이전 완료 기록을 유지한다.

- RG-401: 관련 새 비교가 원래 설명을 보존하고 별도 답변 말풍선으로 추가된다. 반복 비교·오류 재시도·대화 초기화 이후 늦은 응답을 처리한다.
- RG-502: 해오라기의 야간 먹이 활동과 번식기 낮 활동을 출처에 근거해 설명한다. 원자료 `Nocturnal=0`은 검토 출처에서 확인할 수 있고 DB 값을 변경하지 않는다. 다른 종의 0도 야간 활동 부재로 단정하지 않는다. 모든 종의 생태 사실을 전수 검토한 작업은 아니다.
- RG-402: 활성 자료의 38개 범주값을 한국어로 표시한다. 알려지지 않은 값은 번역 확인 필요, 결측은 자료 없음으로 안내하며 원본 값은 보존한다.
- RG-403: 확인된 먹이 구성에 따라 여러 아이콘을 표시한다. 척추동물·물고기를 구분하고 서로 다른 자료의 비율을 합산하지 않는다. 카드 뒷면에서 기준과 출처를 확인한다.
- RG-404: 사용할 수 있는 사진이 없거나 제공처·파일 조회가 실패해도 설명과 카드를 유지한다. 상태 안내·재시도를 제공하며 다른 종의 사진으로 대체하지 않는다.
