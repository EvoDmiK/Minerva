## 1. 개요 및 목적

[[Work/RobinGraph/작업기록/1xx DB·저장소/작업 백로그|1xx DB·저장소 작업 백로그]] · [[Work/RobinGraph/RobinGraph 작업 백로그|전체 작업 백로그]]

사용자가 백로그의 착수 대기 작업이었던 RG-101의 첫 단계 진행을 승인했다. 이번 작업의 목표는 TEST 환경에서 읽기 전용으로 문헌 청크 규모, 전문·벡터·하이브리드 검색 지연(p50/p95), 정책 필터 탈락률 및 서버 메모리 지표를 실측하여 PostgreSQL(pgvector) 분리의 필요성을 판단하는 기준선을 확보하는 것이다.

- 정책 필터 동작
- 메모리 및 PG 인프라 확인
- 판단과 후속 과제

## 4. 검증 근거 및 트러블슈팅

사용자가 백로그의 착수 대기 작업이었던 RG-101의 첫 단계 진행을 승인했다. 이번 작업의 목표는 TEST 환경에서 읽기 전용으로 문헌 청크 규모, 전문·벡터·하이브리드 검색 지연(p50/p95), 정책 필터 탈락률 및 서버 메모리 지표를 실측하여 PostgreSQL(pgvector) 분리의 필요성을 판단하는 기준선을 확보하는 것이다.

실행 중인 TEST 앱은 M4 16GB Mac(`192.168.219.97:8000`)의 `robingraph-api-test`이며, Neo4j는 32GB Mac(`bolt://192.168.219.98:7687`), PostgreSQL은 NAS(`192.168.219.99:5433` `robingraph_test`)다. 스크립트에서 target과 Neo4j URI를 강제 확인하고, PostgreSQL DB도 일치할 때만 조회했다.

새로 추가된 `scripts/measure_chunk_search.py`는 순수 읽기 전용 TEST 계측 스크립트다.
- `bootstrap_index_chunks`, DDL, 쓰기 트랜잭션, 적재 함수를 전혀 호출하지 않는다.
- 기존 프로덕션 검색 코드를 변경하지 않고 동일한 `Neo4jHybridSearch.search` 및 내부 쿼리(`_RECHECK_AND_CITE_QUERY`)를 그대로 활용한다.
- 집계 수치, 지연 통계, 오류 타입만 출력하며 문헌 본문, 벡터 데이터, 비밀번호는 결과물로 내보내지 않는다.
- PostgreSQL 조회 시 `default_transaction_read_only=on`과 `statement_timeout`을 설정해 metadata만 안전하게 조회했다.
- 계측 보조 스크립트(`inventory.py`, `memory.py`)는 `docs/verification/assets/2026-10-18-rg101/`에 함께 보존했다.

기존 `data/eval/v1/search-questions.jsonl`의 5개 fixture 질의를 사용했다.
- **임베딩 지연 분리**: 실제 설정된 임베딩 서비스(Jina API)에 5회 요청하여 각 질의의 512차원 벡터를 1회씩 먼저 생성한 뒤, DB 측정 시에는 생성된 벡터를 메모리에서 재사용하여 순수 DB 검색 시간에서 외부 네트워크/임베딩 시간을 분리했다 (합성 벡터나 mock API가 아님).
- **측정 방식**: 모드별 1회 전체 질의 warmup을 실행한 뒤, 10회 반복 × 5질의 = **모드별 50표본**을 측정했다 (concurrency 1, warm sequential baseline). 부하/스케일 테스트가 아니다.
- p50은 중앙값(median), p95는 nearest-rank 방식으로 계산했다.

| 검색 경로 | 표본 수 | p50 (ms) | p95 (ms) | 최대 (ms) |
|---|---:|---:|---:|---:|
| 전문 검색 전체 | 50 | 3.945 | 6.806 | 11.232 |
| 벡터 검색 전체 | 50 | 8.920 | 18.262 | 20.909 |
| 하이브리드 전체 | 50 | 9.504 | 10.851 | 25.447 |
| 전문 쿼리 단계 | 50 | 1.910 | 2.643 | 5.691 |
| 벡터 쿼리 단계 | 50 | 4.358 | 4.612 | 4.631 |
| 정책 재확인 단계 | 50 | 1.862 | 2.383 | 3.286 |
