# 카드 비율 자료 영역 중앙 정렬·생활 방식 요약·기존 평가 뱃지 표시

## 1. 개요 및 목적

2026-10-09 사용자가 까치 카드 뒷면을 제시하고 먹이 구성·먹이 활동 위치 아래의 상자와 내용을 중앙 정렬하도록 요청했다. 먹이 활동 위치는 먹이 유형처럼 짧게 설명하고 다음 줄에는 `비율 자료 없음`만 표시하도록 요청했다. 이어 평가 연도가 다른 종도 보유한 평가 자료로 뱃지를 만들라고 요청했다. 두 요청을 같은 최종 TEST 배포에 반영했다.

- 점선 상자는 자체 `margin: 0 auto`가 있었지만 `.message p` 문단 스타일의 우선순위가 더 높아 좌우 자동 여백이 적용되지 않았다. 제목은 가운데이고 상자만 왼쪽으로 치우쳤다.
- 정성 자료 대체 표시가 긴 주 생활 방식 전체와 별도의 범위 설명까지 상자에 담아 줄바꿈·말줄임이 많았다.
- 앞선 보전 등급 작업은 참고평가를 별도 줄로 제공하면서 주 뱃지는 `평가 범위 확인 필요`로 유지했다. 평가 연도가 다르다는 이유로 원자료를 삭제한 것은 아니었지만, 뱃지에서 보유 평가 등급을 바로 볼 수 없었다.

프런트엔드의 기존 출처·식별자 검증을 통과한 참고평가만 사용한다. 테스트의 기대 문구를 새 계약에 맞춰 변경했다.

- `src/robingraph/api/static/chat.js`: 짧은 생활 방식, 부연 title, 참고평가 뱃지·평가 연도.
- `src/robingraph/api/static/styles.css`: 대체 상자 중앙 정렬 우선순위.
- `tests/frontend/chat_ui.test.js`: 실제 보존된 title 및 참고평가 뱃지 기대값 수정.
