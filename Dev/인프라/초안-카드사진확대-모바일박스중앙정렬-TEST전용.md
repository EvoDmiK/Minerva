# 앞면 사진 비율 통일·모바일 비율 자료 박스 정렬 — TEST 전용

> 자동 증류 초안 · 원천 [[Work/RobinGraph/작업기록/4xx 채팅 UI·카드/2026-10-09-카드사진확대-모바일박스중앙정렬-TEST전용]] · 분류 근거 {"인프라":1,"자동화":0,"관측성":0,"데이터":1}

## 1. 개요 및 목적

사용자는 청둥오리·도도 카드 스크린샷을 비교해, 청둥오리 사진도 도도처럼 크게 보이게 하고 카드 기본 상태에서 스크롤 없이 전체 정보를 표시하도록 요청했다. 모바일 뒷면의 `먹이 구성`·`먹이 활동 위치`에 비율 자료가 없을 때 나타나는 점선 박스도 가운데 정렬하도록 요청했다.

사용자의 운영 배포 제한을 유지한다. 구현·검증·NAS TEST 배포까지 수행하며 Production 이미지 교체·재시작·DB 쓰기·main 병합은 하지 않는다. 보전 등급·종 이름·생태 자료 자체를 바꾸는 작업은 아니다.

## 4. 검증 근거 및 트러블슈팅

사용자의 운영 배포 제한을 유지한다. 구현·검증·NAS TEST 배포까지 수행하며 Production 이미지 교체·재시작·DB 쓰기·main 병합은 하지 않는다. 보전 등급·종 이름·생태 자료 자체를 바꾸는 작업은 아니다.

- 기존 앞면 사진 영역은 `flex: 1 0 auto`로 남는 높이를 흡수했다. 먹이 배지 여러 줄과 사진 전환 버튼이 있는 종은 그만큼 사진 높이가 줄었다. 원본 사진의 종횡비는 absolute 배치된 이미지라 이 차이의 직접 원인이 아니었다.
- 변경 전 TEST API의 실제 종 프로필을 브라우저 카드 렌더러에 넣어 측정했다. 1280×900 Chrome 화면에서 청둥오리 사진은 394×267.66px, 도도는 394×367.53px, 까치는 394×345.59px였다. 전체 카드 높이는 모두 820px였지만 사진 비율이 달랐다.
- 사진 슬롯의 논리 높이만 같게 해도 전체 카드의 화면 맞춤 축소 배율이 다르면 최종 물리 크기는 달라진다. 따라서 사진 비율과 실제 표시 크기, 화면에 들어오는지 여부를 함께 측정한다.
- 비율 자료가 없는 점선 박스에는 기존에도 `margin: 0 auto`와 텍스트 중앙 정렬이 있었다. 재현한 기본 화면에서는 중심 차이가 없었다. 모바일에서 박스·제목·도넛 래퍼에 서로 다른 정렬 규칙이 적용되지 않도록 열 자체의 정렬을 명시적으로 보강한다. 확인하지 못한 기존 중앙 정렬 오류를 재현했다고 기록하지 않는다.

- PC 앞면의 사진 영역을 남는 높이를 경쟁하는 flex 항목에서 사진 비율을 유지하는 항목으로 바꾼다. 사진 프레임은 가로:세로 7:6으로, 가로로 낮았던 청둥오리 사진을 높인다.
- 사진은 기존 `object-fit: cover`를 유지한다. 프레임에 맞춰 가장자리가 잘릴 수 있다. 원본 사진을 변형하거나 합성하지 않는다.
- 기존 전체 카드 맞춤 기능이 콘텐츠 높이에 따라 카드 전체를 비례 축소하므로 같은 사진 비율이라도 종별 최종 px 크기까지 같다고 주장하지 않는다.
- 모바일의 기존 큰 사진 영역과 화면 맞춤 동작은 유지하는 별도 규칙을 둔다. PC 사진 비율 통일 때문에 모바일 사진이 작아지는 것을 방지한다.
- 먹이 구성·활동 위치 열은 세로 flex와 `align-items: center`로 정렬하고 제목과 실제 도넛 래퍼에는 열 전체 너비를 준다. 실제 비율 자료·정성 설명·완전 자료 없음 상태 모두 같은 열의 중심선을 따른다.
- 먹이 배지·사진 전환 버튼·관찰 포인트·종 정보는 유지한다. 카드 기본 상태에서 세로 스크롤을 만들지 않는다.
- 기존 상세 토글(`측정값 더 보기`, `분류 계통 보기`, `항목·비율`)을 사용자가 펼치면 가독성을 위해 스크롤을 허용하는 별도 기능은 이번 변경 대상이 아니다. 아래 무스크롤 검증은 상세 토글을 닫은 기본 양면 상태를 뜻한다.

`tests/frontend/chat_ui.test.js`: 이전 가변 사진 슬롯의 CSS 단정을 공통 PC 비율·모바일 큰 슬롯 유지 단정으로 수정했다.

`docs/verification/assets/2026-10-09-card-photo-layout.cjs`: 실제 TEST 종 프로필을 사용하는 재현 가능한 Chrome 검증 도구. PC 두 크기와 모바일 두 크기, 실제 청둥오리·도도·까치, 자료 없음·긴 설명을 함께 검증한다. 기본 양면 화면 맞춤·휠 입력 무스크롤·점선 박스 중심·사진 전환·모바일 CDP 터치 스와이프를 확인한다. 실제 앱의 의도 분석 또는 답변 생성 품질 검증과 구분한다.
