# 카드 앞면 관찰 포인트 위 빈 공간 제거(TEST·PROD 반영, 배포 조율)

> 자동 증류 초안 · 원천 [[Work/RobinGraph/작업기록/4xx 채팅 UI·카드/2026-10-09-카드-앞면-빈공간-제거-TEST배포]] · 분류 근거 {"인프라":2,"자동화":0,"관측성":1,"데이터":1}

## 1. 개요 및 목적

사용자가 앞면 스크린샷(`주 생활 방식` 아래가 크게 비고 `관찰 포인트`가 맨 아래에 붙어 있음)을 보내며 다음을 요청했다.

- 카드 크기는 그대로 두고 그 빈 공간을 없앤다.
- `주 생활 방식` 아래에 구분선을 두고 `관찰 포인트`를 위로 올린다.

## 2. 핵심 아키텍처 및 원칙

- 요청 배경과 목표
- 원인 (실측)
- 변경 내용
- 변경 전후 동작
- 검증 (실제 실행 결과)
- 배포 조율과 발생한 문제
- 커밋·배포 정보
- 남은 한계
- 최종 상태 (다른 세션의 통합 보고와 제가 읽기 전용으로 직접 확인한 결과)

## 4. 검증 근거 및 트러블슈팅

제가 한 일은 코드·TEST 배포·검증까지다. PROD 배포와 `main` 반영은 다른 세션(`dev-3`의 Codex)이 통합해 처리했다(아래 "배포 조율"과 "최종 상태" 참조).

처음에는 사진 슬롯 자체(`.species-media`)에 상한을 줬다. 뒷면 토글을 연 상태로 앞면을 보는 경우 사진 영역은 커지고 미디어는 상한에서 멈춰 사진 아래에 약 400px가 비는 것을 측정으로 확인해, 상한을 사진 영역 전체로 옮겼다.

`tests/frontend/chat_ui.test.js`: 옛 `margin-top: auto` 단정을 새 규칙으로 바꾸고, 공통 규칙이 모바일 전용 블록 밖에 있고 상한·구분선·모바일 이중선 방지가 있는지 확인하는 테스트 1개를 추가했다.

| 항목 | 결과 |
|---|---|
| 프런트엔드 `node --test tests/frontend/*.test.js` | 281개 통과, 실패 0(다른 세션의 테스트 포함, 모의 DOM) |
| Python 전체 | 771개 중 통과, 건너뜀 37(기존 DB 옵트인 등), 실패 0 |
| 실제 Chrome(헤드리스 CDP), 로컬 서버가 TEST Neo4j를 읽음(외부 LLM·MLflow 비활성), 청둥오리 앞면 | 변경 후 PC 900px 간격 85→10px(사진 216→290px, 프레임 820px 동일), PC 700px 59→9px, 모바일 8px·`border-top` 0 유지. 뒷면 토글을 모두 연 뒤 앞면: 사진 영역 480px, 기본 정보↔관찰 포인트 10px. 스크린샷으로 구분선 위치와 관찰 포인트가 바로 아래 붙는 것을 확인 |
| NAS TEST 배포 | 이미지 `robingraph-api:test-frontgap-a10baf7`, healthy, 재시작 0, OCI revision `a10baf7…`, `verify` ok(`deployment_target: test`), 서빙되는 CSS에 새 규칙·구분선·`margin-top: auto` 제거 확인 |

측정한 화면의 `관찰 포인트`는 이 로컬 환경에서 관찰 자료가 없어 "출처가 확인된 관찰 자료가 아직 없습니다." 문구 상태였다. 항목이 있는 실제 관찰 목록으로는 렌더링을 확인하지 못했다.
