# 홈랩 인증서·접속 경로 문서 안내

실제 환경의 접속·운영 기록을 포함한 원문은 공개 Git에서 분리하여 Vault의 비공개 영역에 보존했다.

- Vault 원문: [[Private/인프라/2026-10-02-홈랩-인증서·Cloudflare·접속-경로-비교-정리]]
- 관리 기준: [[Dev/인프라/인프라 문서 저장 정책]]

이 파일은 공개 안내문이다. 실제 도메인·연결 경로·인증서 운영 이력·접근 통제 세부사항은 포함하지 않는다. 비공개 원문은 공개 저장소를 clone해도 제공되지 않는다.

최신 공개본 정리는 과거 Git 커밋·외부 복사본 제거를 뜻하지 않는다.
